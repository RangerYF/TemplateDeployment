# physics07

This repository contains the standalone P07 thermodynamics simulation module and its shared `@physics/core` package.

## Contents

- `packages/p07-thermodynamics`: P07 simulation source
- `packages/core`: shared rendering, UI, simulation, and graph utilities
- `dist/P-07-热力学模拟器.html`: built single-file output for direct preview
- `docs/P07-thermodynamics-prd.md`: Chinese PRD and refactor requirements for the P07 template
- `docs/P07-thermodynamics-model-data.md`: model data, parameters, formulas, visual specs, and art asset requirements

## Usage

```bash
pnpm install
pnpm build:p07
```
