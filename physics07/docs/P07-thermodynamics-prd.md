# P-07 热力学与气体分子模拟器 PRD

## 1. 产品定位

高中热学中，学生很难把压强、温度、体积的宏观变化与微观分子运动建立直觉联系。液柱封闭气体、气缸活塞、双活塞等模型还涉及压强平衡和受力分析，过程抽象、计算链条长，课堂讲解成本高。

P-07 热力学与气体分子模拟器用于从微观粒子碰撞出发，可视化宏观热力学量变化，并提供液柱模型和气缸模型的交互演示，帮助老师在课堂上讲清楚“现象、图像、公式、计算”之间的对应关系。

## 2. 目标用户与使用场景

目标用户：高中物理老师，不要求有任何编程基础。

典型使用场景：

- 演示等温、等压、等容三种变化过程，并显示对应图像。
- 在液柱密封气体模型中演示升温后气柱长度变化，并与公式结果对照。
- 在气缸/双活塞模型中演示加热后活塞移动方向、最终位置、压强和体积变化。

## 3. 演示模块

| 模块 | 主要内容 |
| --- | --- |
| 气体分子微观模拟 | 分子热运动，温度与速率分布 |
| 三种气体实验 | 等温、等压、等容变化对比 |
| 液柱密封模型 | 竖直、水平、倾斜液柱，温度变化影响 |
| 气缸/双活塞模型 | 温度变化，活塞移动方向及压强体积变化 |
| 布朗运动 | 大颗粒无规则运动模拟 |

## 4. 核心功能

### 4.1 气体分子微观动画

容器内气体分子随机运动。升高温度时，分子平均速率增大，粒子运动加快；减小体积时，碰撞频率增大，压强增大。

需要支持：

- 容器内粒子随机热运动动画。
- 温度调节，联动分子平均速率。
- 体积调节，优先支持拖动活塞改变体积。
- 实时显示 `p`、`V`、`T` 数值。
- 自动验证 `pV/T = 常数`。

### 4.2 三种变化过程对比

三个容器并排显示，分别演示：

- 等温变化：`T` 不变，`p` 与 `V` 成反比。
- 等压变化：`p` 不变，`V` 与 `T` 成正比。
- 等容变化：`V` 不变，`p` 与 `T` 成正比。

需要支持：

- 三个过程同屏对比。
- 对应的 `p-V`、`p-T`、`V-T` 图像实时绘制。
- 与气体分子微观动画和布朗运动相关能力统一设计，避免模块割裂。

### 4.3 液柱密封气柱模型

液柱模型是常考计算题，需要体现压强平衡、气体状态方程和几何关系。

需要支持：

- 竖直管，开口向上。
- 竖直管，开口向下。
- 水平管。
- 倾斜管。
- 初始温度、末温度、气柱长度、液柱长度、管截面积设置。
- 升温或降温后，气柱长度和压强变化以动画和数值显示。
- 支持两端液柱封闭的对称模型。
- 计算过程需展示压强平衡和公式推导。

补充要求：

- 功能 3、4 是常考计算题，详细计算参考飞书文档《关于功能3、4的常考计算》。
- 美术资源需要覆盖试管、U 型管、气缸、活塞。

### 4.4 气缸/双活塞模型

气缸模型需要体现受力分析、压强平衡、温度变化和活塞最终位置。

需要支持：

- 单活塞气缸：可调温度，展示活塞移动方向、最终位置、压强和体积变化。
- 双活塞模型：中间气体加热，两侧活塞各自移动，清晰展示压强平衡条件。
- 数值结果与受力分析、状态方程保持一致。
- 计算过程需要明确展示。

### 4.5 布朗运动

大颗粒被若干气体分子随机撞击，呈现无规则运动。

需要支持：

- 大颗粒无规则运动轨迹留存。
- 可调颗粒大小。
- 展示颗粒越大，运动越规则或随机扰动越不明显的趋势。

## 5. 界面布局建议

```text
┌──────────────────────────────────────────────────────┐
│               顶部：演示模块选择（5个按钮）             │
├──────────────────┬───────────────────────────────────┤
│   左侧面板       │     中央演示区                      │
│   ─────────────  │   （分子动画 / 液柱示意图 / 气缸图）│
│   参数输入区     │                                    │
│   · 温度 T       │                                    │
│   · 体积/活塞    │                                    │
│   · 液柱长度     │                                    │
│   · 管的方向     ├───────────────────────────────────┤
│                  │     下方：p-V / p-T / V-T 图像区   │
│   ─────────────  │                                    │
│   状态显示       │                                    │
│   p = ___        │                                    │
│   V = ___        │                                    │
│   T = ___        │                                    │
│   pV/T = ___     │                                    │
└──────────────────┴───────────────────────────────────┘
```

布局要求：

- 顶部使用 5 个模块按钮，而不是仅依赖下拉选择。
- 左侧面板承载参数输入和状态显示。
- 中央演示区根据模块切换分子动画、液柱示意图或气缸图。
- 下方图像区展示过程图像，重点支持 `p-V`、`p-T`、`V-T`。

## 6. 验收标准

- 等温压缩时，`pV` 保持不变，数值误差不超过 1%。
- 液柱模型中，升温后气柱变化量与公式计算一致。
- 双活塞模型中，两侧移动方向正确，最终压强相等。

## 7. 后续重构提示

当前模板可能需要较大调整。后续开发建议将功能拆成清晰的状态层、计算层、渲染层和 snapshot bridge 层。

新增或调整业务状态时，需要同步检查：

- `getSnapshot()`
- `loadSnapshot(snapshot)`
- `validateSnapshot(snapshot)`
- `payload` 字段是否仍符合“最小可恢复状态”原则

随机模拟类能力应优先保存 `seed + params + engineVersion + resultSummary`，避免把大量粒子状态、逐帧历史或中间过程塞入 snapshot。
