【增加功能】高中数学中常出现比赛类的赛制问题，特别是轮空类，不知道能不能直观展示出来，例如2020年新高考卷的统计题，学生对这种实验的运行就比较不容易理解
比如：（2020·新课标Ⅰ）甲、乙、丙三位同学进行羽毛球比赛，约定赛制如下：

累计负两场者被淘汰：比赛前抽签决定首先比赛的两人，另一人轮空；每场比赛的胜者与轮空者进行下一场比赛，负者下一场轮空，直至有一人被淘汰；当一人被淘汰后，剩余的两人继续比赛，直至其中一人被淘汰，另一人最终获胜，比赛结束。

经抽签，甲、乙首先比赛，丙轮空。设每场比赛双方获胜的概率均为 1/2。

（1）求甲连胜四场的概率；

（2）求需要进行五场比赛的概率；

（3）求丙最终获胜的概率。
