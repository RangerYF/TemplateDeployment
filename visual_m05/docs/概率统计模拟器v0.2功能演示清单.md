## 一、单步模拟可视化动画（反馈: 教师#4「看不到模拟过程」+ 团队#4「学生觉得抽象」）

v0.1 的单步模式仅在图表上方显示文字结果（如"正面(H)"），缺乏视觉冲击力。v0.2 为全部 5 种古典/几何概型添加了**先播放动画、再更新图表**的单步可视化体验。

### 1. 【增强】抛硬币翻转动画
- **实现方式**：CSS keyframe `@keyframes coin-flip`，scaleX 1→0→1 配合 perspective 容器产生立体翻转效果。在 scaleX=0 中点（300ms）切换正/反面内容。`onAnimationEnd` 回调后更新图表。
- **涉及文件**：
  - `src/index.css`：新增 `@keyframes coin-flip` + `.animate-coin-flip` 类
  - `src/components/scene/SingleStepAnimation.tsx`：新建 `CoinFlipAnim` 子组件
  - `src/editor/store/animationStore.ts`：新增 `singleAnimating` / `singleAnimResult` / `startSingleAnim()` / `endSingleAnim()` 状态
  - `src/components/scene/SimulationCanvas.tsx`：集成动画覆盖层 + `handleAnimComplete` 回调
  - `src/components/panels/ControlPanel.tsx`：`handleSingleStep` 改为异步（先 `startSingleAnim`，动画结束后才 `buildPartialResult + setResult`）
- **演示**：选择「掷硬币」→ 单次模式 → 点击「运行一次」→ 观察硬币翻转动画（绿色=正面 / 蓝色=反面）→ 动画结束后图表才更新

### 2. 【增强】掷骰子滚动动画
- **实现方式**：`requestAnimationFrame` 驱动，总时长 1200ms，二次缓出函数 `1-(1-t)²` 控制闪烁间隔递减（快→慢），最终锁定目标点数。骰子面用 SVG 60×60 标准点阵绘制（1~6 面）。
- **涉及文件**：
  - `src/components/scene/SingleStepAnimation.tsx`：新建 `DiceFace` + `DiceRollAnim` 子组件
- **演示**：选择「掷骰子」→ 单次模式 → 点击「运行一次」→ 观察骰子快速闪烁后逐渐停定 → 锁定后 400ms 延迟更新图表
- **多骰子效果**：设置骰子数为 3 → 运行一次 → 3 个骰子同时并排滚动

### 3. 【增强】两骰子之和滚动动画 + 求和显示
- **实现方式**：复用 `DiceRollAnim`，传入 `showSum` 属性。动画锁定后在骰子下方显示 `= 求和值`（绿色粗体）。
- **涉及文件**：
  - `src/components/scene/SingleStepAnimation.tsx`：`DiceRollAnim` 增加 `showSum` 参数
  - `src/engine/singleStep.ts`：`twoDiceSum` 的 `runOneTrial` 返回 `{ faces, sum }` 对象
- **演示**：选择「两骰子之和」→ 单次模式 → 运行一次 → 骰子滚动 → 停定后显示 `= 8`（两个骰子面值之和）

### 4. 【增强】摸球实验可视化动画
- **实现方式**：3 阶段动画（bag → draw → done），SVG 绘制袋中球（红/白色圆形，按比例分布，最多显示 20 个），抽球后袋中球变淡，下方显示抽出的红球。
- **涉及文件**：
  - `src/components/scene/SingleStepAnimation.tsx`：新建 `BallDrawAnim` 子组件
  - `src/components/scene/SimulationCanvas.tsx`：传递 `ballDrawContext: { redCount, whiteCount }` 给动画组件
- **演示**：选择「摸球实验」→ 单次模式 → 运行一次 → 看到袋中红白球 → 600ms 后抽球淡出 → 1200ms 后显示结果

### 5. 【增强】约会相遇问题时间流动动画
- **实现方式**：`requestAnimationFrame` 驱动 3 秒时间扫描（0 → T 分钟），甲乙两人以圆形图标从画面两侧**滑入**约会地点，等待时间到后**滑出**离开。底部时间轴光标实时扫描，甲/乙等待条实时生长。若二人同时在场，头顶出现脉动绿色高亮。
- **涉及文件**：
  - `src/components/scene/SingleStepAnimation.tsx`：新建 `MeetingAnim` 子组件（完全重写，替代原静态 3 阶段方案）
  - `src/engine/singleStep.ts`：meetingProblem 加入 `AnimatableType`（从 `MultiAnimatableType` 移出），新增 `runOneTrial` / `getTrialDisplay` / `buildPartialResult` 三个函数的 meetingProblem 分支
  - `src/components/scene/SimulationCanvas.tsx`：传递 `meetingContext: { T, t }` 给动画组件
- **动画细节**：
  - 顶部实时时钟显示 `时间: X.X / 60 分钟`
  - 中央约会地点标记（虚线）
  - 甲（绿色）从左侧滑入，乙（蓝色）从右侧滑入
  - 二人同时在场时头顶脉动绿色感叹号
  - 先到的人等不到就滑出离开
  - 底部时间轴：等待条实时生长 + 光标扫描
  - 3 秒结束后显示"相遇了！"或"未相遇" + 各自到达时间
- **演示**：选择「约会相遇问题」→ 单次模式 → 运行一次 → 观察 3 秒动画（甲乙走来走去、时间线推进）

### 6. 【增强】动画期间按钮禁用
- **修改**：`ControlPanel.tsx` — 单步动画播放期间（`singleAnimating === true`），「运行一次」和「重置」按钮均 disabled，防止重复点击
- **演示**：单次模式动画播放中 → 观察按钮变灰不可点

## 二、动画系统增强

### 7. 【增强】新增「极慢」速度档位（5 档速度）
- **修改**：
  - `src/hooks/useAnimationEngine.ts`：SPEED_CONFIG 从 4 档扩展为 5 档
  - `src/components/panels/ControlPanel.tsx`：SPEED_LABELS 新增"极慢"

| 档位 | 标签 | 每秒试验数 | 适用场景 |
|------|------|-----------|---------|
| 1 | 极慢 | ~2 次/秒 | 逐步观察每次实验变化 |
| 2 | 慢 | ~8 次/秒 | 教学演示 |
| 3 | 中 | ~83 次/秒 | 常规播放 |
| 4 | 快 | ~667 次/秒 | 快速浏览 |
| 5 | 极快 | ~6250 次/秒 | 大数据量快速收敛 |

- **演示**：运行任一模拟 → 动画播放 → 切换 5 档速度，观察播放节奏变化

### 8. 【修复】动画控制独立化（各模拟互不阻塞）
- **问题**：v0.1 中暂停一个模拟的动画后，切换到其他模拟的「运行模拟」按钮也被禁用
- **修改**：`ControlPanel.tsx` — 按钮 disabled 状态改为仅作用于**当前模拟**（`isPlayingThis = animSimId === activeSimId && status === 'playing'`），其他模拟不受影响
- **演示**：选掷硬币 → 运行 → 动画播放 → 暂停 → 切换到掷骰子 → 确认「运行模拟」按钮可正常点击

### 9. 【增强】运行模拟后自动播放动画
- **问题**：v0.1 点击「运行模拟」后直接显示最终结果图表，缺少渐进展示过程
- **修改**：
  - `ControlPanel.tsx`：`handleRun` 执行 `RunSimulationCommand` 后，自动调用 `startAnimation()` 开始动画播放
  - `SimulationCanvas.tsx`：`handleRun` 同样在 Placeholder 页面点击「开始模拟」后自动播放
- **适用范围**：全部支持动画的模拟类型（coinFlip / diceRoll / twoDiceSum / ballDraw / meetingProblem / monteCarloPi / buffonsNeedle）
- **演示**：选择任一模拟 → 点击「运行模拟」→ 图表自动开始动画播放（无需手动点击「动画播放」按钮）

### 10. 【优化】移除绿色结果气泡中的重复计数
- **问题**：v0.1 单步模式的绿色结果气泡显示如"反面(T) ×10"，"×10"含义不明确（是第10次？还是连续10次反面？）
- **修改**：`SimulationCanvas.tsx` — 移除气泡中的 `× {singleTrials.length}` 文本，仅显示本次结果
- **演示**：单步模式多次运行 → 绿色气泡只显示"正面(H)"或"反面(T)"，不再带计数后缀
