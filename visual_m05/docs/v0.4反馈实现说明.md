反馈④：正态分布 σ=2.8 时竖线倾斜（Bug）
用户原话
正态分布：图像此处竖线不直（调整标准差 2.8 之后，表示范围 2.8 处的竖线倾斜，而不是垂直的），这是什么原因？查看一下给我汇报。
根因汇报
代码层面 `<line x1={spx(v)} y1={MT} x2={spx(v)} y2={MT+PH} />` 中 x1 = x2，几何上应严格垂直。**真正成因是浏览器的亚像素抗锯齿**：
- spx(2.8) 返回浮点数（如 510.5）
- 浏览器在 0.5 像素位置绘制 1px 宽 stroke 时，**会向相邻像素染色以模拟连续位置**
- 配合 `vectorEffect="non-scaling-stroke"` 在 SVG 缩放下，相邻几行染色不完全对齐
- **视觉上呈现"歪斜"假象**，本质不是几何 bug，是浏览器渲染优化的副作用
修复（双重保险）
1. 整数化 x 坐标：`x1 = x2 = Math.round(spx(v))`
2. shapeRendering="crispEdges"：显式锐利渲染
3. 同时去掉 vectorEffect="non-scaling-stroke"
适用范围：σ 边界线（±1σ ±2σ ±3σ）、均值竖线、X 轴刻度线全部加这套修复。

反馈⑥：随机游走模型
用户原话
建议添加随机游走模型（评估一下添加在哪里比较好）。需要一维 + 二维两种。
归类决策
归到几何概型组（与蒙特卡洛、约会问题、布丰投针并列，强调"路径与轨迹的几何特征"）。
实现方案
一维随机游走 randomWalk1D
- 规则：每步以 p 概率向右 +1，1-p 向左 -1
- 参数：steps(2-1000) / pRight(0-1) / numPaths(1-6) / n(模拟次数)
- 可视化：
  - 上半：前 N 条样本路径折线图（多色）+ 期望线 + ±1σ ±2σ 参考线
  - 下半：n 步后终点位置频率分布柱状（蓝色实心）vs 二项分布理论概率（红色描边）柱对照
- 理论对照：E[X_n] = n(2p-1)，σ[X_n] = 2√(np(1-p))，终点位置 k 的理论概率 = C(n,(n+k)/2)·p^r·(1-p)^(n-r)
二维随机游走 randomWalk2D
- 规则：每步等概率向上/下/左/右 4 方向走 1 单位
- 参数：steps(10-2000) / numPaths(1-6) / n(模拟次数)
- 可视化：
  - 左：480×480 平面格点路径地图，多色样本路径 + 起点(0,0)红心 + 各终点彩色实心
  - 右：所有 n 次模拟终点距离 √(x²+y²) 频率直方图 + 理论期望线 √(πn/2)
- 理论对照：E[√(x²+y²)] ≈ √(πn/2)（大 n 渐近 Rayleigh）
按步动画
两者均接入 isMultiAnimatable，路径随步数逐步增长，动画末端有彩色圆点跟踪当前游走位置，速度可选（极慢/慢/中/快/极快）。

实现方案
归类：几何概型组（与随机游走并列，强调"随时间演化的状态过程"）
类型：MarkovChainParams { states: string[]; transition: number[][]; initial: number[]; steps: number; n: number; showSteadyState: boolean }
预设场景（4 个）：
- MC-WEATHER：天气链 晴/阴/雨（经典三态）
- MC-PASS-BALL：三人传球（高考典型，演化 1/3 振荡收敛）
- MC-RAINY-MOOD：心情链 开心/平静/烦躁
- MC-2STATE：简单二态链
引擎（markovChain.ts）
- 状态空间采样：sampleDist 按累积概率分布
- n 条路径模拟：每条路径 steps 步
- distribution[t][i] = 第 t 步状态为 i 的频率（n 次平均）
- 稳态分布 computeSteadyState：从均匀分布出发反复左乘转移矩阵，迭代 200 次或收敛（tol=1e-10）
- 校验 validateMatrix：每行和 = 1，所有项 ≥ 0；validateDistribution：长度 + 和 = 1
Renderer（MarkovChainRenderer.tsx）
- 左上：转移矩阵热力图（CELL 36px，单元格颜色深浅 = 概率大小，对角线高亮）
- 右上：状态分布演化折线图（每个状态一条折线 + 稳态参考虚线 + 当前位置彩色圆点跟踪）
- 下半：第 currentStep 步分布柱状（实色）vs 理论稳态（描边）对比
Inspector（MarkovChainInspector.tsx）
- 状态名列表（+ 加 / × 删，2-6 个）
- N×N 矩阵编辑（每单元格 number input，每行末显示 Σ + 「1」一键归一化按钮）
- 初始分布编辑（含全局「归一化」按钮）
- 预设下拉切换
- 校验提示：行和或初始分布和 ≠ 1 时红色提示
按步动画
接入 isMultiAnimatable，演化按步播放：
- displayN 控制当前步
- 折线 polyline 只取 distribution.slice(0, currentStep+1)，末端彩色圆点跟踪
- 标题动态显示 `步 X/N`
- 底部柱状图实时切换为"第 X 步分布"
- 速度可选（极慢/慢/中/快/极快）

反馈⑩：线性回归非线性模型
用户原话
可视化中心-教学模板库-概率统计模拟，线性回归方程需要添加一些需要变换后才能按回归方程求解的类型，类似 y = c₁e^(c₂x) 这种形式。
实现方案
扩展 LinearRegressionParams：
- modelType: 'linear' | 'exponential' | 'power' | 'log' | 'quadratic' | 'reciprocal'
- autoRecommend: boolean

6 种模型

模型 | 形式 | 线性化方法 | 数据约束
--- | --- | --- | ---
线性 | y = a + bx | 直接 | 无
指数 | y = a·e^(bx) | ln(y) = ln(a) + bx | y > 0
幂函数 | y = a·x^b | ln(y) = ln(a) + b·ln(x) | x > 0 且 y > 0
对数 | y = a + b·ln(x) | x → ln(x) 后线性 | x > 0
二次 | y = ax² + bx + c | 3×3 法方程 Cramer 求解 | ≥ 3 点
倒数 | y = a + b/x | x → 1/x 后线性 | x ≠ 0

自动推荐最佳模型
勾选后引擎跑完全部 6 种模型并按 R² 选最高者；未启用时若有更优模型 R² 高 0.02+，stats 显示"更优模型建议"。
教学增强
- equation（原始方程，如 `ŷ = 2.5·e^(0.3x)`）+ linearizedEquation（线性化方程，如 `ln(ŷ) = 0.916 + 0.300x`）双重展示
- R² 决定系数（不仅线性 r）
- 数据约束不满足时显示原因（如 `指数模型要求所有 y > 0`），禁用计算
- 拟合曲线密集采样（80 点），非直线模型用 polyline 而非直线两端点
- 与 v0.3 交互（增/删/拖拽）完全兼容
数据契约验证（独立 Node 端）
- y = e^x 数据：指数模型拟合 y = 0.9940·e^(1.0020x)，R² = 1.0000（数据扰动 < 0.6%）
- y = x² 数据：二次模型 y = 1.0000x² + 0.0000x + 0.0000 精确还原
文件清单
- 修改（重写）：src/engine/simulations/linearRegression.ts（含通用 linearLeastSquares + 5 种非线性 fit + calculateR2 + sampleCurve）
- 修改：src/types/simulation.ts（RegressionModelType 联合 + Params 扩展 + DEFAULT_PARAMS 补 modelType / autoRecommend）
- 修改：src/components/scene/renderers/LinearRegressionRenderer.tsx（用 result.curvePoints 替代直线，标题显示 equation + R²）

用户操作流程
1. 顶部菜单 → 回归分析 → 线性回归
2. 顶部 Inspector「回归模型」下拉，6 种可选
3. 切到「教师输入」模式输入 y = e^x 数据：`1,2.72  2,7.39  3,20.1  4,54.6`
4. 模型切到「指数」→ 主图变成指数曲线，方程显示 `ŷ ≈ 1.00·e^(1.00x)` R²≈1.0000
5. 勾选「自动推荐最佳模型」→ 系统自动选指数模型，stats 显示"自动推荐最佳模型: 指数 y = a·e^(bx)"
6. 切到线性模型 → R² 显著下降，stats 显示"更优模型建议: 指数（R²=1.0000）"
7. 数据中加 y≤0 后切到指数模型 → "指数模型要求所有 y > 0" 提示
