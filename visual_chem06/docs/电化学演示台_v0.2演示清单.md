### 反馈 8：双液原电池 — 补 Zn²⁺；盐桥不要 KNO₃；解释避免混合的原因

| 项目 | 内容 |
|---|---|
| **原始问题** | G02 缺少 Zn²⁺ 迁移展示；盐桥使用 KNO₃ 存在氧化副反应风险；"避免混合"的解释不够到位 |
| **修复措施** | ① 补入 Zn²⁺ 生成迁移流（短程通道 `bath-near-left`）；② 盐桥改为 `MgSO₄ 盐桥`；③ keyframe 和 environmentTips 补充副反应方程式 `Zn + Cu²⁺ → Zn²⁺ + Cu`（铜直接沉积在锌表面，化学能全部转化为热而非电能） |
| **信息来源** | 教师反馈 + 高中教材：KNO₃ 中 NO₃⁻ 在酸性环境有氧化性，MgSO₄ 为惰性盐桥电解质 |
| **验证方式** | 打开 G02 → 盐桥标签显示"MgSO₄ 盐桥"；Zn²⁺ 仅在左槽附近扩散；当前说明含副反应方程式 |
| **状态** | ✅ 已完成 |
