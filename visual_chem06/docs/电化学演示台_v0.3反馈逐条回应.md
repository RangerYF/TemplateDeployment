# 电化学演示台 v0.3 反馈逐条回应

> 文档用途：面向教师反馈逐条说明问题分析、改进方案与当前实现。  
> 对应版本：v0.3  
> 项目目录：`visual_chem06_new`

## 一、反馈原文

能看出来针对前一次的意见有做修正，目前的问题如下：

1.绝对不能简单地把负极和阳极等同，正极和阴极等同。这是统一存在的严重问题。在原电池中电极是自发输送电子电流的，通常不称为阴阳极，一定要标注的话，会容易误导学生，但不算错；然而电解池的阴阳极就是完全标错了，电源才是阴阳极，电解池的电极板没有阴阳极。

2.有很多离子的电荷被自己图案点盖住了，建议调一下图层前后设置，不然离子的电荷被挡住看着很奇怪。或者适当降低图例的密度。

3.粒子迁移中写电子可以补充注明是经过外电路迁移（部分模型漏了这个解释）。如果是电解池，则要改为：阳极→电源正极丨电源负极→阴极。

4.逐步前进这个按钮实际使用起来的效果很迷惑，可以删除，或者动作帧更细化一点。

5.有的离子由于要发生电极反应，所以可以在动画中表示为定向迁移。有的离子则是在某电极生成然后在溶液扩散，此时动画不适用定向迁移。建议作出区分。

接下来是个例

6.铜锌双液原电池，反应中性会生成氢氧化物沉淀，要改为酸性或酸性。所有使用硫酸铜作为电解液的模型，都是酸性。

7.铅蓄电池 ，既然电极表面要生成硫酸铅，为何不见硫酸根离子？之前说过不是定向迁移而是往两电极吸附，这次看好像硫酸根直接删了。

8.电解水缺少生成气体（氢气氧气）的动态图注。（包括下一条，主要是气泡图案和背景的对比太弱，看不出有气体生成）

9.电解饱和食盐水是逐步生成氢氧化钠的过程，说中性显然不合适。生成氯气和氢气的动态图注最好也补一下；氢氧根是在阴极生成的，然后向阳极扩散而非定向迁移。

pH严格要求p小写H大写，不能按首字母大写来。浓度影响氯离子和氢氧根在阳极竞争放电原理可以说是错的，真实原因是电极过电位带来的选择性差异，所以不要展示这个知识。高中不学过电位和动力学竞争，也不必面向学生深究知识。

10. 铜的电解精炼做的基本合格，溶液中可以逐渐产生少量游离的活泼金属离子。

11. 电解熔融氯化钠，还是补上氯气动态图注。熔盐电解质调色可以再鲜艳一点。

12. 铝土矿电解，“碳阳极”不是“炭阳极”

13. 电镀能不能随着时间进度让工件逐渐上色？所有涉及铜电极的建议调色接近真实紫红色。逐个解决问题。

## 二、逐条回应

### 1. 电极标注不能把正负极与阴阳极简单等同

**问题分析**

v0.2 中为了补全标注，舞台把原电池电极显示成“负极 / 阳极”“正极 / 阴极”，容易让学生机械记忆“负极=阳极、正极=阴极”。电解池部分还把电极板直接按正负极和阴阳极绑定展示，与教师反馈的教学口径不一致。

**改进方案**

普通原电池舞台按教学需要显示正负极，不再把阴阳极并列贴在电极旁；铅蓄电池放电按原电池口径显示 Pb 负极 / PbO₂ 正极，充电按电解口径只显示阴极/阳极。电解池舞台强调外接电源关系，显示“接电源负极的电极 / 接电源正极的电极”，避免把电解槽电极板直接等同为电源正负极。反应式和关键帧中仍可使用“得电子/失电子”的过程语言解释反应。

**实现**

- `src/components/scene/ElectrochemStage.tsx`：`ElectrodeLabel` 根据模型类型区分显示口径；无极性字段时不渲染空白极性行。
- `src/data/electrochemModels.ts`：原电池模型的舞台角色字段清空或弱化，不再显示“负极 / 阳极”“正极 / 阴极”绑定；铅蓄电池放电场景显示正负极，充电场景只显示阴极/阳极。
- `docs/电化学演示台_v0.3演示清单.md`：更新该反馈的验收说明。

### 2. 离子电荷被图案点盖住

**问题分析**

v0.2 中粒子小球和文字标签在同一组里逐个绘制，后绘制的小球可能覆盖前一个粒子的电荷文本，尤其是 `SO₄²⁻`、`Cu²⁺`、`OH⁻` 这类带上标的标签。

**改进方案**

将粒子圆点层和标签层拆开绘制：先统一绘制所有圆点，再统一绘制所有文字标签；同时降低扩散粒子的视觉密度。

**实现**

- `src/components/scene/ElectrochemStage.tsx`：粒子圆点和文字标签分层渲染，文字层最后绘制；标签描边加厚，提升电荷可读性。
- 对膜区和扩散粒子降低显示数量，减少遮挡。

### 3. 电子迁移需注明外电路；电解池需改为电源路径

**问题分析**

部分模型只写“电子由 A 到 B”，没有明确电子经过外电路；电解池若写成“阳极到阴极”会漏掉外接电源的作用，容易误导为电极间直接迁移。

**改进方案**

原电池统一写“经外电路”。电解池统一写成“阳极 → 电源正极丨电源负极 → 阴极”或按具体极板材料替换两端名称。

**实现**

- `src/data/electrochemModels.ts`：统一修改 `electronDirection` 和电子流 `note`。
- `src/components/scene/ElectrochemStage.tsx`：舞台底部“电子 / 电流”图例直接读取新路径文本。
- `src/components/panels/ControlPanel.tsx`：右侧“外电路”卡片显示同一套电子路径。

### 4. “逐步前进”按钮迷惑

**问题分析**

“逐步前进”按钮实际跳转到下一个关键帧，但动画帧之间并非真正细分反应步骤，使用时容易让人误以为它是逐帧动画推进。

**改进方案**

删除该按钮，保留播放/暂停、重置、速度调节和时间轴拖动。需要定位关键帧时，由老师直接拖动时间轴。

**实现**

- `src/components/panels/ControlPanel.tsx`：移除 `SkipForward` 图标、`stepForward` 状态调用和“逐步前进”按钮。
- `docs/功能演示清单.md`：旧清单改为指向 v0.3，说明该按钮已移除。

### 5. 区分定向迁移与生成后扩散

**问题分析**

v0.2 中部分生成物离子也沿固定方向移动，看起来像定向迁移。例如阴极生成的 `OH⁻`、铅蓄电池中从溶液参与两极反应的 `SO₄²⁻`、粗铜阳极释放出的少量杂质离子，都不适合表现为普通强定向迁移。

**改进方案**

新增粒子运动语义：定向迁移粒子保持沿通道运动；生成后扩散粒子降低密度，并从生成/来源位置向周围扩散。对于铅蓄电池 `SO₄²⁻`，单独使用更强方向偏置：放电时从溶液中部向两极扩散，充电时从两极回到溶液中部，标签固定跟随粒子，避免跳动。

**实现**

- `src/types/electrochem.ts`：`ParticleStream` 增加 `movementMode?: 'directed' | 'diffusion'`。
- `src/components/scene/ElectrochemStage.tsx`：对 `movementMode: 'diffusion'` 的粒子降低数量并从来源位置扩散；对铅蓄电池 `SO₄²⁻` 使用强方向扩散和固定相对标签。
- `src/data/electrochemModels.ts`：将 `Zn²⁺` 局部扩散、铅蓄电池 `SO₄²⁻`、食盐水 `OH⁻`、铜精炼杂质离子标为扩散；盐桥 `Mg²⁺/SO₄²⁻` 仍保持定向迁移。

### 6. CuSO₄ 体系应为酸性

**问题分析**

Zn-Cu 双液原电池、浓差电池、电镀液等模型使用 CuSO₄ 溶液。若标为中性，可能引出氢氧化物沉淀等不必要问题。

**改进方案**

所有使用 CuSO₄ 作为电解液的当前模型统一标为酸性或酸性 CuSO₄。

**实现**

- `src/data/electrochemModels.ts`：
  - Zn-Cu 双液原电池 `environment` 改为“酸性”，右槽标签改为“酸性 CuSO₄ 溶液”。
  - 浓差电池两侧改为“低/高浓度酸性 CuSO₄”，动画只显示电子与 `SO₄²⁻` 过膜迁移，不额外显示 `Cu²⁺` 粒子。
  - 电镀液改为“酸性 CuSO₄ 电镀液”。
- `docs/电化学演示台_v0.3演示清单.md`：反馈 6 对应验收方式更新。

### 7. 铅蓄电池缺少硫酸根离子

**问题分析**

v0.2 为避免误导，把 `SO₄²⁻` 定向迁移流删除过度，导致两极生成 `PbSO₄` 却看不到硫酸根来源。

**改进方案**

恢复 `SO₄²⁻` 粒子，但不表现为单向定向迁移；放电时表现为从溶液中部向两极附近扩散并参与 `PbSO₄` 生成，充电时表现为从两极附近回到溶液中部。

**实现**

- `src/data/electrochemModels.ts`：铅蓄电池放电场景增加两组 `SO₄²⁻` 扩散粒子，分别从溶液中部向 Pb 极和 PbO₂ 极扩散；充电场景补充两组 `SO₄²⁻` 从两极附近回到溶液中部的扩散说明。
- `src/components/scene/ElectrochemStage.tsx`：扩散粒子使用 `movementMode: 'diffusion'` 处理；铅蓄电池 `SO₄²⁻` 使用 `diffusionBias: 'strong-directional'` 和固定标签，方向更明确且标签不跳动。

### 8. 电解水缺少 H₂/O₂ 动态图注

**问题分析**

电解水虽然有气泡动画和顶部气体标签，但关键帧没有明确说明“当前正在生成 H₂/O₂”，且气体名称没有贴在动态气泡旁，气泡与背景对比也偏弱。

**改进方案**

补充关键帧文字，增强气泡描边和填色对比，并在气泡旁显示随气泡移动的 H₂ / O₂ 动态标签。

**实现**

- `src/data/electrochemModels.ts`：电解水酸性/碱性场景都增加“气体生成”关键帧，说明阴极 H₂、阳极 O₂ 生成。
- `src/components/scene/ElectrochemStage.tsx`：气泡统一增加深色描边，并根据电极反应在气泡旁动态显示 H₂ / O₂ / Cl₂ / CO₂ 标签。

### 9. 电解饱和食盐水的碱性生成、气体图注、OH⁻ 扩散与 pH 写法

**问题分析**

v0.2 把食盐水环境写成中性不合适，因为通电后会逐步生成 NaOH。`OH⁻` 是阴极生成后向阳极方向的溶液扩散，不应显示为强定向迁移。同时不应向高中学生展示 Cl⁻/OH⁻ 竞争放电原因或过电位等动力学内容。

**改进方案**

环境改为“逐步显碱性 / 课堂实验”；只展示课堂要求的产物和来源；`OH⁻` 改为从阴极附近向阳极方向扩散的粒子，不作为定向迁移粒子；不再展示竞争反应卡片或竞争原因。全局统一使用 `pH` 写法。

**实现**

- `src/data/electrochemModels.ts`：
  - `environment` 改为“逐步显碱性 / 课堂实验”。
  - 关键帧补充 `Cl₂`、`H₂` 生成和 `NaOH` 逐步生成。
  - `OH⁻` 粒子设为 `movementMode: 'diffusion'`，并加方向偏置，表现为从阴极生成后向阳极方向扩散。
  - 移除 `competition` 数据，不再出现竞争提示卡片。
- `src/components/scene/ElectrochemStage.tsx`：此前右上角竞争提示已移除；气泡旁动态显示 `H₂`、`Cl₂` 标签。
- `src/components/panels/KnowledgePanel.tsx`：不再渲染竞争反应说明。

### 10. 铜电解精炼应有少量活泼金属离子

**问题分析**

铜精炼中粗铜阳极除 Cu 外，Zn、Fe、Ni 等活泼杂质也会进入溶液，但不在阴极析出。v0.2 已有阳极泥，但缺少少量活泼金属离子的可视化。

**改进方案**

增加少量 `Zn²⁺/Fe²⁺` 扩散粒子，说明其从粗铜阳极进入溶液并留在溶液中。

**实现**

- `src/data/electrochemModels.ts`：铜精炼场景新增 `Zn²⁺/Fe²⁺` 粒子流，使用 `movementMode: 'diffusion'`；关键帧和溶液颜色说明同步补充。

### 11. 熔融 NaCl 补 Cl₂ 图注，熔盐颜色更鲜艳

**问题分析**

熔融 NaCl 的阳极生成 `Cl₂`，需要明显动态图注。原熔盐颜色偏浅，不够突出高温熔融盐场景。

**改进方案**

在阳极气泡旁动态显示 `Cl₂` 标签并随气泡移动；熔盐底色改为更鲜艳的橙黄色渐变。

**实现**

- `src/data/electrochemModels.ts`：熔融 NaCl 关键帧“阳极放 Cl₂”补充气体生成说明；`solutionShifts` 改为更高饱和度的橙黄色。
- `src/components/scene/ElectrochemStage.tsx`：含 `Cl₂` 的气泡使用黄绿色填充并加描边，气泡旁动态显示 `Cl₂` 标签。

### 12. “碳阳极”不是“炭阳极”

**问题分析**

炼铝模型中 v0.2 使用了“炭阳极”表述，教师要求改为“碳阳极”。

**改进方案**

炼铝模型展示文案统一使用“碳阳极”。

**实现**

- `src/data/electrochemModels.ts`：炼铝模型的 summary、apparatusNote、tags、环境提示、舞台标签、关键帧、表面说明统一为“碳阳极”。
- `docs/电化学演示台_v0.3演示清单.md`：反馈 12 写入验收项。

### 13. 电镀工件随时间上色，铜电极颜色接近紫红色

**问题分析**

v0.2 中铜色偏普通棕橙，电镀工件表面变化主要是厚度变化，不够直观。

**改进方案**

统一铜材料颜色为更接近真实铜的紫红色；电镀工件随进度从金属色渐变为铜色。

**实现**

- `src/components/scene/ElectrochemStage.tsx`：
  - `getElectrodeColor()` 中铜色改为 `#A94328`。
  - 新增 `getElectrodeFill()`，当待镀金属使用 `coat` 效果时按进度从灰色渐变到铜色。
- `src/data/electrochemModels.ts`：电镀模型表面说明和关键帧说明补充“紫红色铜镀层逐步上色”。
