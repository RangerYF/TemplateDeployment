# 电化学演示台 v0.3 功能演示清单

> 版本：v0.3  
> 日期：2026-05-11  
> 范围：基于 v0.2 教师反馈，修正电极标注、粒子层级、迁移语义、气体图注、模型事实与铜色表现。

## 一、核心交付

| # | 新增 / 优化 / 修复 | 用户操作 | 预期效果 |
|---|---|---|---|
| 1 | 原电池不再把负极/阳极、正极/阴极简单等同 | 打开 Zn-Cu 单液、Zn-Cu 双液、燃料电池、浓差电池；再打开铅蓄电池放电/充电 | 普通原电池不再用“负极 / 阳极”“正极 / 阴极”绑定展示；铅蓄电池放电显示 Pb 负极 / PbO₂ 正极，充电只显示阴极/阳极 |
| 2 | 电解池电子路径改为电源路径表达 | 打开电解水、食盐水、铜精炼、熔融 NaCl、炼铝、电镀 | 外电路说明显示“阳极 → 电源正极丨电源负极 → 阴极” |
| 3 | 粒子标签层级修复 | 开启粒子标签并播放任一模型 | 电荷文字绘制在小球上层，不再被后绘制粒子遮住 |
| 4 | 粒子密度与扩散语义优化 | 播放铅蓄电池、电解食盐水、铜精炼 | 定向迁移粒子保持沿通道运动；生成后扩散的粒子以低密度、轻微散开方式显示 |
| 5 | 删除“逐步前进”按钮 | 打开右侧“演示控制” | 控制区只保留播放、重置、速度和可拖动时间轴，避免按钮行为误导 |
| 6 | 气体生成图注明显化 | 播放电解水、食盐水、熔融 NaCl、炼铝 | H₂ / O₂ / Cl₂ / CO₂ 气泡对比度增强，关键帧补充动态图注说明 |
| 7 | 铜色统一接近真实紫红色 | 查看所有铜电极、铜沉积、电镀 | 铜板和铜镀层使用更接近真实铜的紫红色 |
| 8 | 电镀工件随进度上色 | 打开“电镀（铜镀层）”并拖动时间轴 | 工件从金属色逐步变为紫红色铜镀层 |

## 二、反馈逐条回应

| 反馈 | 处理结果 | 验证方式 |
|---|---|---|
| 1. 不能简单把负极=阳极、正极=阴极；电解池标注错误 | 普通原电池舞台不再并列显示阴阳极；铅蓄电池放电显示正负极，充电只显示阴极/阳极；电解池舞台标签改为“接电源负/正极的电极”，避免把电极板直接等同为电源正负极；电子说明改成外电路或电源路径 | 打开 G01/G02 看普通原电池标注；打开铅蓄电池放电/充电核对标签；打开 E01 看“接电源负极的电极/接电源正极的电极” |
| 2. 离子电荷被图案点盖住 | 粒子圆点和标签拆成两层绘制，标签最后绘制；膜区和扩散粒子降低密度 | 开启粒子标签，观察 SO₄²⁻、Cu²⁺、OH⁻ 等电荷可读 |
| 3. 电子迁移需注明外电路；电解池需改电源路径 | 所有原电池电子流写明“经外电路”；所有电解池电子路径写为“阳极 → 电源正极丨电源负极 → 阴极” | 查看右侧“外电路”卡片和舞台底部“电子 / 电流”图例 |
| 4. “逐步前进”按钮迷惑 | 从右侧控制面板移除该按钮，保留可拖动时间轴用于精确定位关键帧 | 打开控制面板，不再出现“逐步前进” |
| 5. 区分定向迁移与生成后扩散 | 新增 `movementMode: 'diffusion'`，用于 Zn²⁺、SO₄²⁻、OH⁻、杂质离子等生成/局部扩散粒子 | 铅蓄电池 SO₄²⁻、食盐水 OH⁻、铜精炼杂质离子不再呈强定向迁移 |
| 6. 铜锌双液和 CuSO₄ 模型酸性 | Zn-Cu 双液、浓差电池、电镀液明确为酸性 CuSO₄；单液仍为酸性导电溶液 | 查看模型环境副标题、槽体标签和装置说明 |
| 7. 铅蓄电池缺少 SO₄²⁻ | 放电场景恢复 SO₄²⁻，表现为从溶液中部向两极扩散；充电时从两极附近回到溶液中部 | 打开铅蓄电池放电/充电，观察 SO₄²⁻ 扩散方向 |
| 8. 电解水缺少气体动态图注 | 电解水酸性/碱性关键帧都加入 H₂/O₂ 气体生成说明；气泡描边增强 | 打开电解水，拖动到 68% 附近 |
| 9. 食盐水不是中性；OH⁻ 在阴极生成后扩散；不要展示竞争原理；pH 写法 | 环境改为“逐步显碱性 / 课堂实验”；移除竞争提示 UI 与数据；OH⁻ 标为扩散；全局保留小写 p 大写 H | 打开食盐水电解，查看环境提示、pH 指示和 OH⁻ 运动 |
| 10. 铜电解精炼可逐渐产生少量活泼金属离子 | 增加 Zn²⁺/Fe²⁺ 少量扩散粒子与说明，保留阳极泥 | 打开铜精炼，播放并查看粒子迁移说明 |
| 11. 熔融 NaCl 补 Cl₂ 图注，熔盐更鲜艳 | Cl₂ 气体图注和气泡保留并增强；熔盐颜色改为更鲜艳的橙黄色 | 打开熔融 NaCl，观察右极气泡和熔盐底色 |
| 12. “碳阳极”不是“炭阳极” | 炼铝模型所有展示文案统一改为“碳阳极” | 打开炼铝模型，查看模型卡片、标签、关键帧和提示 |
| 13. 电镀随时间上色；铜色接近紫红色 | 工件电极采用随进度混色；铜材料映射改为紫红色 | 打开电镀并拖动时间轴，工件逐步上色 |

## 三、重点演示路径

| 场景 | 操作 | 讲解重点 |
|---|---|---|
| Zn-Cu 双液原电池 | 选择“Zn-Cu 双液原电池（盐桥）”→播放 | 酸性 CuSO₄、电子经外电路、Zn²⁺ 局部扩散、盐桥补偿 |
| 铅蓄电池 | 选择“铅蓄电池”→播放放电→切换充电 | SO₄²⁻ 两极附近参与 PbSO₄ 生成；充电电子路径经过电源 |
| 电解饱和食盐水 | 选择“电解饱和食盐水”→播放 | 阴极析 H₂ 并逐步生成 OH⁻/NaOH；OH⁻ 扩散；不展示竞争原理 |
| 铜电解精炼 | 选择“铜的电解精炼”→播放 | Cu²⁺ 定向到阴极，少量活泼金属离子扩散，不活泼杂质形成阳极泥 |
| 电镀 | 选择“电镀（铜镀层）”→拖动时间轴 | 工件作为阴极逐步覆盖紫红色铜镀层 |
