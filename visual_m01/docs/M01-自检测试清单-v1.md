# M01 自检测试清单 v1

## 测试目的

本轮自检从真实用户视角出发，目标有两类：

1. 遍历 M01 当前提供给用户的显性功能与常见操作路径，发现已有 bug、异常状态、数学错误、渲染问题和功能联动问题。
2. 以老师、教研、学生的使用习惯评估体验，记录入口不清楚、步骤繁琐、反馈不足、视觉干扰、功能鸡肋或容易造成困扰的地方。

## 用户角色假设

- 老师备课：希望快速选几何体或预置题目，补辅助线、截面、角度/距离标注，并导出或保存。
- 课堂演示老师：希望画面清楚，旋转和切换视图顺手，操作反馈明确，不被标签和面片遮挡。
- 学生自学：希望知道当前选中了什么、下一步该点什么，错误操作能得到清楚提示。
- 教研/内容生产：希望预置场景、AI 生成场景、导入导出和参数调整稳定可靠。

## 问题分级

- P0：阻断核心流程，页面崩溃、数据丢失、无法继续使用。
- P1：核心功能错误或数学结果错误，高频路径明显不可用。
- P2：功能可用但有明显异常、体验困扰或需要绕路。
- P3：轻微体验问题、文案不清、视觉细节或低频问题。

## 问题类型

- Bug：功能承诺与实际行为不一致。
- 数学正确性：计算、几何构造、可视化表达有误。
- 体验问题：能用但不顺手、不清楚、不符合用户直觉。
- 性能问题：卡顿、加载慢、交互延迟明显。
- 兼容问题：不同几何体、浏览器尺寸、导入数据下表现不一致。

## 首轮重点观察点

- 用户是否知道下一步应该点什么。
- 场景中是否有看起来像按钮但不能点击的元素。
- 标签、面片、辅助线是否遮挡教学重点。
- 不同几何体同一功能表现是否一致。
- 操作失败是否有提示，提示是否能指导用户修正。
- 撤销重做是否覆盖用户认为应该能撤销的操作。
- 数学结果是否既正确又表达清楚。

## 首批自检发现

### M01-SC-001 参数数字输入会在输入过程中连续提交

- 类型：设计确认项
- 严重级别：不作为问题处理
- 发现批次：B1-03
- 用户场景：老师或内容生产者直接在右侧参数框输入边长、高、半径等数值。
- 复现步骤：选中几何体，在参数数字输入框中输入多位数字或小数。
- 实际表现：每次按键都会提交一次参数变更，几何体即时响应。
- 期望表现：保留即时响应设计。
- 影响范围：所有右侧参数数字输入；棱锥高度/侧棱长联动输入。
- 初步判断：这类参数面板常见即时更新设计，用户确认当前交互合理。
- 建议修复：不修复，保持原设计。
- 状态：已确认不处理；此前尝试改为失焦提交，现已撤回。

### M01-SC-002 导入失败使用浏览器 alert 打断操作

- 类型：体验问题
- 严重级别：P3
- 发现批次：B4-01
- 用户场景：导入 JSON 文件格式错误或解析失败。
- 复现步骤：点击导入，选择非法 JSON 或非 M01 场景文件。
- 实际表现：浏览器原生弹窗打断当前工作流，视觉上也和编辑器内其他提示不一致。
- 期望表现：使用场景内统一轻提示，说明失败原因且不阻断后续操作。
- 影响范围：数据导入失败路径。
- 初步判断：`DataIOPanel` 中直接调用 `alert`。
- 建议修复：复用 `useNotificationStore` 展示错误信息。
- 状态：已修复。

### M01-SC-003 自检基线存在 lint 错误

- 类型：工程质量 / 潜在性能问题
- 严重级别：P2
- 发现批次：基础静态检查
- 用户场景：后续每轮自检需要依赖 lint/build 判断改动是否引入风险。
- 复现步骤：执行 `npm run lint`。
- 实际表现：存在曲线线段渲染 effect 内同步 setState、AI 操作无效赋值、无用 eslint-disable。
- 期望表现：lint 基线干净，后续新增问题能被及时识别。
- 影响范围：曲面曲线段渲染、AI 标注操作、编辑页初始化。
- 初步判断：历史实现遗留，build 不受影响但会降低自检可信度。
- 建议修复：按 lint 提示做等价收敛，不改变功能语义。
- 状态：已修复。
