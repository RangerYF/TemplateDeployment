# P03 光学实验台 — 画面升级设计方案

> 日期：2026-06-04 | 核心标准：拟真、炫酷、方便教学

## 一、设计目标

将5个光学模块的画面从"能用"升级到"惊艳"：
- 折射/透镜：新增Three.js 3D场景，透明介质+发光光线+角度标注
- 干涉/衍射/薄膜：2D精美化，辉光效果+色彩渲染升级

核心原则：**物理引擎不动，只改渲染层。** 3D场景使用已有的求解器数据驱动。

## 二、折射模块 — 6个3D场景

### 通用3D技术栈
- 介质：`MeshPhysicalMaterial(transmission:1, ior:可调, roughness:0)` — 真实玻璃/水质感
- 光线：`TubeGeometry(r=0.3)` + `MeshBasicMaterial(toneMapped:false, color:激光色)` — 自发光效果
- 光线辉光：UnrealBloomPass(threshold:0.2, strength:0.4) — 柔和光晕
- 角度标注：CSS2DRenderer
- 场景：深色背景(#0a0e1a)，环境光+方向光
- 交互：OrbitControls(拖拽旋转) + 右侧面板调参数
- 切换：场景浮窗中每个子实验可选2D/3D

### 实验1：单平面界面
- 透明平板介质（上空气下玻璃），MeshPhysicalMaterial
- 入射/折射/反射三条发光光线
- 法线虚线、角度弧线标注
- 全反射时反射光更亮，折射光消失

### 实验2：玻璃砖
- 透明长方体，清晰看到内部光路
- 入射→上界面折射→内部传播→下界面折射→出射
- 重点：侧移量的3D可视化（入射线和出射线平行偏移）

### 实验3：半球介质
- 透明半球Mesh（自定义LatheGeometry）
- 平面入射/球心入射两种模式
- 曲面法线方向用箭头标示

### 实验4：光纤
- 双层透明圆柱（纤芯+包层）
- 光在纤芯内反复全反射，每次反射点有角度标注
- 弯曲模式：圆柱沿弧线弯曲（TubeGeometry+自定义path）
- 弯曲时漏光效果（部分光从包层透出，橙色弱光线）

### 实验5：视深与视高
- 透明容器装半透明蓝色水
- 水下实物（发光小球）
- 三条折射光线从物体到水面再到观察者
- 虚像位置用虚线球体+虚线光线延长线标示
- 标注实际深度h和视深h'

### 实验6：斯涅尔窗
- 已完成，保持现状

## 三、透镜模块 — 3D场景

- 透明凸/凹透镜（LatheGeometry旋转体，MeshPhysicalMaterial）
- 光学导轨（长条形平台）
- 物体（蜡烛：圆柱体+火焰粒子 或 箭头：几何体）
- 三条特殊光线穿过透镜（发光Tube）
- 实像/虚像渲染（实像=实体，虚像=半透明+虚线光线）
- 屏幕（平面Mesh，可显示"对焦"效果）
- 焦点标记（F, F', 2F, 2F'）用CSS2D标签

## 四、2D精美化 — 干涉/衍射/薄膜

### 双缝干涉
- Canvas条纹加径向辉光（高斯模糊叠加）
- 明纹中心亮度渐变更自然
- 白光模式：彩色分离的色散效果更鲜艳
- 装置图SVG线条加阴影深度感

### 单缝/圆孔衍射
- 艾里斑渲染：中心亮斑加柔和bloom效果
- 暗环/明环的对比度提升
- 比较模式（3波长并排）色彩更鲜明

### 薄膜干涉
- 肥皂膜：用物理准确的薄膜干涉色彩（而非近似RGB）
- 牛顿环：同心环加径向辉光渐变
- 劈尖：等厚干涉条纹加色彩渐变

## 五、实施顺序

1. 折射实验1（单平面界面3D）— 验证技术方案
2. 折射实验2-5 — 复用技术方案
3. 透镜3D场景
4. 2D精美化（干涉→衍射→薄膜）

## 六、不做的事

- 不改物理引擎
- 不加新实验内容
- 不做移动端3D（性能不够，移动端继续用2D）
