# 体验文档：P-13 电磁感应

更新时间：2026-05-02

## 1. 体验目标

本轮体验不是只看“有没有几个样例能跑”，而是确认 `P-13 电磁感应` 是否已经形成一套老师可直接拿来课堂试讲的独立模块。

本轮重点确认 4 件事：

- `/#p13` 是否已经是清晰的独立入口，而不是零散预设集合。
- 主模型是否覆盖了课堂最常讲的几条主线：基础动生、楞次定律、单棒、双棒、竖直导轨、统一工作台。
- 单棒 / 双棒 / 竖直导轨是否已经统一到同一套 workbench 壳层，便于连续讲题。
- 当前对外开放能力和内部已具备但未主推能力，是否已经区分清楚。

## 2. 体验入口

建议优先使用独立入口：

- `/#p13`
- `/#p13-builder`

如果是线上体验，可直接使用：

- `https://edumind-em-feedback.vercel.app/#p13`
- `https://edumind-em-feedback.vercel.app/#p13-builder`

进入方式：

1. 从首页进入 `P-13 电磁感应`。
2. 或从模板库进入 `P-13` 独立模块卡片。
3. 需要在一个页面里切结构、改参数、看图表时，直接进入 `/#p13-builder`。

## 3. 当前对外开放范围

当前 `/#p13` 首页实际对外开放的是 8 个标准模型入口 + 1 个工作台入口：

- `P13-BASE-001` 矩形线框穿过匀强磁场
- `EMI-001` 磁棒-线圈楞次定律
- `EMI-011` 单棒基础（纯电阻电路）
- `EMI-012` 单棒 + 含电源
- `EMI-013` 单棒 + 含电容
- `EMI-021` 双棒基础（无摩擦）
- `EMI-024` 双棒 + 恒外力
- `EMI-031` 竖直导轨单棒
- `P13-BUILDER` 实时组装台

需要特别说明：

- 当前首页和主路由主推的双棒模型是 `EMI-021` 与 `EMI-024`。
- `EMI-022` 双棒 + 摩擦、`EMI-023` 双棒 + 电容在底层逻辑中已具备，但当前不是首页主入口，也不是当前对外主推体验路径。

## 4. 页面结构怎么理解

### 4.1 统一 workbench 页面

以下页面已经统一到同一类课堂工作台壳层：

- `EMI-011`
- `EMI-012`
- `EMI-013`
- `EMI-021`
- `EMI-024`
- `EMI-031`
- `P13-BUILDER`

这类页面的结构基本一致：

- 顶部：模型标题、返回入口、当前关键读数徽标
- 左侧：参数区、模型约定、当前联动值、显示选项
- 中间：视觉演示区
- 下方：时间图表区
- 右侧：分析面板 + 结果区

统一显示开关包括：

- 向量箭头
- 标注文字
- 网格背景
- 坐标轴

### 4.2 非统一 workbench 页面

以下两页属于独立教学页：

- `P13-BASE-001`
- `EMI-001`

说明：

- `P13-BASE-001` 虽然已经有完整参数、图表、分析和结果区，但它是独立的基础动生页，不和单棒/双棒共用模型切换轨。
- `EMI-001` 是楞次定律专项页，重点是“拖动 / 自动播放 + 分步判断”，不走标准 workbench 图表结构。

## 5. 各主线推荐怎么体验

### 5.1 基础动生

入口：

- `P13-BASE-001`

适合讲：

- 线框进入磁场、完全在磁场内、离开磁场时，`Φ / ε / I / F安 / v` 如何联动变化。

当前可直接体验到：

- `v-t / Φ-t / ε-t / I-t` 四张图联动
- 进入 / 全进入 / 离场 / 完全离开四段状态
- 安培力对速度的实时反作用
- 线框可能在边界附近减速甚至停下的真实动力学口径

这页当前应按下面口径理解：

- 不是旧版“匀速穿场 + 只标注安培力”的样例。
- 当前版本已经改成真实动力学近似模型：只要仍在切割磁感线，就会出现 `Φ -> ε -> I -> F安 -> 减速` 的闭环。

### 5.2 楞次定律

入口：

- `EMI-001`

适合讲：

- `N / S` 极插入和拔出时，原磁通量、磁通量变化、感应电流、感应磁场和安培力方向如何判断。

当前可直接体验到：

- 四种典型情况速览
- 拖动磁棒进出线圈
- 一键播放“插入 / 拔出”
- `开始分析 / 下一步 / 重置分析`
- 固定“从右看线圈”的课堂判断口径

这页更适合做方向判断教学，不是终态动力学页。

### 5.3 单棒模型族

入口：

- `EMI-011`
- `EMI-012`
- `EMI-013`

适合讲：

- 动生电动势、回路电流、安培力和导体棒运动之间的耦合。

当前可直接体验到：

- `EMI-011`：纯电阻回路的速度衰减闭环
- `EMI-012`：含电源时的电流方向变化和终态匀速口径
- `EMI-013`：含电容时的充电式、放电式、恒外力式三种课堂情形

其中 `EMI-013` 需要单独说明：

- 充电式、放电式、恒外力式已经统一在同一页面内切换
- 恒外力式会明确标注为“教学简化”
- 该简化口径下，机械侧不把安培力反作用回速度，而是保留 `Uc`、`i` 的建立过程用于教学表达

### 5.4 双棒模型族

入口：

- `EMI-021`
- `EMI-024`

适合讲：

- 相对速度如何建立动生电动势
- 电流如何通过两棒上的安培力把运动耦合起来
- 从“一个棒更快”逐步走向“共同演化”的过程

当前可直接体验到：

- `EMI-021`：无摩擦双棒的共速口径
- `EMI-024`：棒1受恒外力时，外力如何通过感应电流把驱动传给棒2
- `v1-t / v2-t / i-t` 联动
- 分步分析：相对运动 -> 感应电动势 -> 回路电流 -> 两棒安培力

当前对外文档不建议写成：

- `EMI-022`、`EMI-023` 已是标准前台入口

更准确的说法是：

- 双棒底层求解能力不止两支，但当前首页主展示模型是 `EMI-021` 和 `EMI-024`。

### 5.5 竖直导轨

入口：

- `EMI-031`

适合讲：

- 导体棒下落时，重力、感应电流和向上安培力如何逐步达到平衡。

当前可直接体验到：

- `v-t / i-t` 联动
- `mg = B²L²v终 / (R + R棒)` 的终态口径
- `i终`、`v终` 和时间常数读取
- 分步分析：运动方向 -> 感应电动势方向 -> 电流方向 -> 安培力方向

### 5.6 实时组装台

入口：

- `P13-BUILDER`

适合讲：

- 在一个统一工作台中切换高频题型，而不是在首页和多个专页间反复跳转。

当前 builder 已支持：

- 单棒组装：纯电阻、含电源、含电容
- 双棒组装：无摩擦、恒外力
- 竖直导轨标准结构
- 单页内改参数、播放动画、看图表、做分步分析、读结果

当前 builder 的边界：

- 它是 `P13` 专用的模板化实时工作台
- 不是任意拓扑拖拽编辑器
- 不是跨模块混合元件的自由电磁搭建器

## 7. 建议体验任务

可以把下面任务直接发给体验老师：

1. 进入 `P13-BASE-001`，观察线框进入和离开磁场时，`Φ / ε / I / v` 是否容易一起看懂。
2. 进入 `EMI-001`，分别播放 `N 极插入` 和 `N 极拔出`，判断“从右看线圈”的电流方向是否直观。
3. 进入 `EMI-011`，调大 `B` 或减小总电阻，观察导体棒减速是否更明显。
4. 进入 `EMI-013`，切换“充电式 / 放电式 / 恒外力式”，判断三种题型是否容易区分。
5. 进入 `EMI-021`，观察两棒速度是否能直观看出从“有速度差”走向“共速”。
6. 进入 `EMI-024`，观察棒1受恒外力后，棒2是否能明显表现出“被带动起来”的过程。
7. 进入 `EMI-031`，判断“为什么不会一直加速”是否能通过动画和结果区讲清楚。
8. 进入 `P13-BUILDER`，尝试只在同一工作台里切结构和改参数，判断这种课堂流程是否比反复跳页更顺手。

## 8. 体验时重点记录什么

建议重点记录下面几类反馈：

- 理解问题：是否知道每一页到底在讲什么
- 操作问题：是否知道先点哪里、先看哪里、分析按钮是否顺手
- 表达问题：箭头、图表、结果区是否互相打架，还是能形成同一条讲解链
- 模型问题：是否有某一页的物理口径和老师课堂习惯冲突
- 边界问题：老师是否会误以为 `P13-BUILDER` 是任意拓扑拖拽器

建议追问：

- 哪一页最适合直接拿去上课？
- 哪一页虽然能用，但还不够顺？
- 你最希望在同一工作台里连续切换的是哪几类题型？

## 9. 当前对外可怎么说

- `P-13` 已形成 `/#p13` 独立首页 + `/#p13-builder` 实时组装台的双入口。
- 当前已对外开放基础动生、楞次定律、单棒模型族、双棒主模型、竖直导轨和统一工作台。
- 单棒 / 双棒 / 竖直导轨已经统一到同一类 workbench 壳层，适合连续讲题。
- `EMI-013` 已经把单棒含电容的三种课堂高频情形统一到一个页面里。
- `P13-BASE-001` 已从旧的静态样例口径升级为带速度反作用的真实动力学近似演示。

## 10. 当前不应对外宣称什么

- 已支持任意拓扑自由拖拽式电磁感应搭建
- 已支持跨模块任意混合元件组装
- 双棒所有变体都已作为前台标准入口开放
- 已支持复杂自感、接触电阻动态变化、空气阻力等高阶真实效应
- 已具备 PNG 导出、保存/加载工程等完整课件化能力
