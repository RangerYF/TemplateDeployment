## 1. 本轮结论

当前 P-13 的主要问题已经从“模型覆盖不够”切换为“教学表现不够准、不够直观、模块组织不够贴课堂”：

- 模块结构需要重排
  - 单棒电容当前只有一种，需要扩成三种课堂情形。
  - 双棒需要新增“一个棒受恒定外力”的高频模型。
  - 双棒 + 电容当前不应继续作为前台主展示模型。
- 现有若干物理过程展示不完整或有误
  - 单棒 + 电源应表现为“从静止开始加速，最终匀速”。
  - 双棒动画方向需要修正为同向运动。
  - 矩形线框穿磁场需要补 `v-t` 图，并确保磁场区域和线框几何不乱跳。
  - 楞次定律页不能停留在“只有图示、缺少过程动画”的感受。
- 视觉语义不够直观
  - 电流箭头应该直接画在导体棒上。
  - 速度和力箭头要区分颜色，并随大小变化长度。
  - 电阻符号不能再用折线，折线在电学里更像电感线圈。
  - 导轨/线框长度应固定，不能给人“随棒运动而伸长”的观感。

因此，本轮不再采用“P-13 已基本完成，只差 builder 和文档”的判断口径，而应改为：

- P-13 已完成第一轮模型覆盖。
- P-13 正进入第二轮教学质量修正阶段，重点是课堂口径、动画过程和视觉表达。

## 2. 产品范围调整

## 2.1 保留并强化的主模型

- `P13-BASE-001` 矩形线框穿过匀强磁场
- `EMI-001` 磁棒-线圈楞次定律
- `EMI-011` 单棒基础（纯电阻）
- `EMI-012` 单棒 + 电源
- `EMI-013` 单棒 + 电容
- `EMI-021` 双棒基础
- `EMI-022` 双棒 + 摩擦
- `EMI-031` 竖直导轨单棒
- `P13-BUILDER` 模板化实时组装台

## 2.2 需要新增的课堂高频模型

- 单棒 + 电容新增两种情形
  - 电容初始满电，棒初始静止，开关闭合后放电驱动棒运动。
  - 单棒受恒定外力作用，可用“竖直单棒 + 电容”承接恒力口径。
- 双棒新增一种情形
  - 等距导轨下，一个棒受恒定外力作用。

## 2.3 需要降级处理的模型

- 双棒 + 电容当前不作为前台主展示模型。
- 处理方式建议：
  - 保留求解代码和页面，避免直接删逻辑。
  - 从 `/#p13` 首页、模型切换轨、builder 默认选项、教师体验文案中撤下。
  - 如需保留，可作为开发态/内部验证项，不对外主推。

## 2.4 暂不进入本轮范围

- 不等距双棒运动
- 任意拓扑自由拖拽式 P-13 电磁感应搭建
- 自感、接触电阻动态变化、空气阻力等高阶真实效应

## 3. 通性改造项

## 3.1 视觉表达统一修正

- 电流箭头
  - 单棒、双棒、竖直导轨都改为“直接在导体棒上标电流方向”。
  - 回路边框上的电流箭头可以保留，但降为辅助信息。
- 速度箭头
  - 使用统一颜色体系，建议继续沿用蓝色系。
  - 箭头长度按当前速度大小缩放，但要加最小/最大钳制，避免过短看不见或过长穿模。
- 力箭头
  - 使用统一红色系。
  - 安培力、外力、重力要明确区分颜色和位置。
  - 箭头长度按力大小缩放，和速度箭头形成统一规则。
- 读数面板
  - 当前状态卡片继续保留，但不要代替场景内箭头。
  - 核心判断应优先在场景里直接看出来。

## 3.2 电路元件符号修正

- 电阻全部改为小长方体符号。
- 当前单棒页、竖直导轨页、builder 里凡是折线电阻，都应统一替换。
- 电源和电容符号可保留，但需和新的电阻符号对齐尺寸与间距。

## 3.3 轨道与磁场几何修正

- 导轨长度固定，不随棒位置拉伸。
- 线框大小固定，只有参数调整时才改变，不在运动中变化。
- 磁场区域固定在画布中，不做“跟着物体移动”的观感。
- 若当前是通过相对坐标缩放导致视觉变形，需要统一改为“固定舞台 + 物体位移”模式。

## 3.4 图表能力修正

- `P13TimeSeriesChart` 当前只支持单曲线，已不够支撑双棒课堂口径。
- 需要新增或扩展多曲线图表能力：
  - 双棒 `v1-t` 和 `v2-t` 画在同一张图。
  - 后续双棒恒外力也复用同一套图表。
- 基础动生页增加 `v-t` 图。
- 单棒 + 电源页修正 `i-t` 图口径。
- 单棒 + 电容三种情形统一支持 `v-t / i-t / Uc-t`。

## 3.5 首页 / 模型目录 / builder 同步收口

- 首页文案不再主推 `EMI-023`。
- 双棒模型卡片改为“基础 / 摩擦 / 恒外力”三支。
- 单棒电容改为一个总模型入口，页内切三种子情形即可，不必急着拆成三个首页卡片。
- builder 中的单棒、双棒结构选项与首页保持一致，避免首页和工作台可选模型不一致。

## 4. 逐模块修改计划

## 4.1 `P13-BASE-001` 矩形线框穿过磁场

本轮目标：

- 磁场区域固定不动。
- 线框运动过程中大小不变。
- 增加 `v-t` 图。
- 保留“匀速穿场”的基础教学口径，但把动画表现做正确。

具体修改：

- 检查当前舞台实现，确保：
  - 磁场矩形是固定背景区域。
  - 线框只做平移，不做动态缩放。
- 图表区从 `Φ-t / ε-t / I-t` 扩为：
  - `v-t`
  - `Φ-t`
  - `ε-t`
  - `I-t`
- 结果区和说明文案明确：
  - 本模型仍是基础动生基线。
  - `v-t` 为常量线，不引入安培力反作用。

验收口径：

- 线框进入、全在场内、离开三个阶段视觉稳定。
- `v-t` 图为水平直线。
- 线框在运动过程中没有“变大/变小”的观感。

## 4.2 `EMI-001` 磁棒-线圈楞次定律

本轮目标：

- 从“静态判断页”升级为“有过程感的动画判断页”。
- 让老师和学生能明显看到“插入 / 拔出”的过程，而不只是切换结论。

具体修改：

- 保留当前拖动磁棒交互。
- 额外增加自动播放能力：
  - 插入动画
  - 拔出动画
  - 暂停 / 重播 / 回到起点
- 磁棒、线圈、电流方向提示、感应磁场方向提示随时间联动。
- 逐步分析卡片继续保留，但页面观感不能只剩图文卡片。

验收口径：

- 不操作拖拽时也能一键看完整插入/拔出过程。
- 线圈电流方向和感应磁场方向会随动画同步出现。
- 页面不再给人“只有图，没有动画”的感受。

## 4.3 `EMI-011` 单棒基础（纯电阻）

本轮目标：

- 重点突出减速过程。
- 安培力逐渐变小这一点必须在动画里直接看出来。

具体修改：

- 速度箭头长度随 `v` 衰减。
- 安培力箭头长度随 `F安` 衰减。
- 电流箭头直接贴在导体棒上。
- 电路拓扑中的电阻换成长方体符号。
- 导轨画足够长，避免“棒一动，回路形状也跟着拉伸”。

验收口径：

- 只看动画，不看右侧数值，也能看出“棒越来越慢、安培力越来越小”。
- `v-t`、`i-t` 与箭头变化趋势一致。

## 4.4 `EMI-012` 单棒 + 电源

本轮目标：

- 明确表现“棒最初静止，随后加速，最后匀速”。
- 修正 `i-t` 图和终态口径。

具体修改：

- 默认初速度保持为 0。
- 动画强调三段：
  - 初始静止
  - 受电源驱动加速
  - `BLv = ε0` 后进入匀速
- 速度箭头从无到有，再趋于稳定长度。
- 安培力箭头从大到小，最后趋近于 0。
- `i-t` 图修正为趋近 0，而不是错误的持续偏离。

验收口径：

- `v-t` 从 0 单调上升并逐渐趋于水平。
- `i-t` 从初值逐渐趋于 0。
- 页面结果区明确给出“最终匀速”而不是仅给公式。

## 4.5 `EMI-013` 单棒 + 电容

本轮目标：

- 当前单一情形改成三种课堂情形。
- 用同一个总页面承接“充电式 / 放电式 / 恒外力式”。
- 这部分要重点做好全过程演示，因为学生高频混淆。

建议结构：

- `EMI-013` 保留为单棒 + 电容总入口。
- 页内增加情形切换：
  - 充电式：电容初始无电量，棒有初速度。
  - 放电式：电容初始满电，棒初始静止。
  - 恒外力式：棒初始静止，受恒外力，可用竖直单棒 + 电容承接。

### 4.5.1 充电式

- 保留当前已有实现作为第一支。
- 重点强调：
  - 电容逐渐充电
  - 电流逐渐减小到 0
  - 棒最终匀速

验收口径：

- `Uc-t` 单调上升并趋于稳定。
- `i-t` 衰减到 0。
- `v-t` 最终趋于匀速，不是停下。

### 4.5.2 放电式

- 新增初始条件：
  - `Uc_0 > 0`
  - `v0 = 0`
- 开关闭合后由电容放电驱动回路电流，棒开始运动。
- 最终仍收敛到匀速课堂口径。

验收口径：

- 起点时棒静止。
- 动画中能看见“先由电容驱动启动”。
- `Uc-t` 先下降或向终态值收口，`v-t` 从 0 起步上升，`i-t` 最终回到 0。

### 4.5.3 恒外力式

- 采用竖直单棒 + 电容是合理实现方向。
- 但这一支在求解前必须先确认课堂口径：
  - 如果教研坚持“严格匀加速”，则需要明确采用简化模型。
  - 如果按完整电磁耦合求解，过程一般未必严格匀加速。
- 技术计划建议：
  - 先把页面结构、动画、图表、参数区留好。
  - 在求解层把“外力口径”做成可切换或明文写清的简化版。

验收口径：

- 页面上必须写清楚所采用的物理简化。
- 不能在文案里写“匀加速”，结果曲线却明显不是匀加速。

## 4.6 `EMI-021` 双棒基础（等距导轨）

本轮目标：

- 修正动画方向。
- 两棒运动方向应相同。
- `v1-t`、`v2-t` 放到同一张图里显示。

具体修改：

- 舞台中两棒位置和箭头方向按课堂口径重排。
- 同向运动时，箭头应并排可读，不要一上一下互相打架。
- 图表由两张分离的速度图改成一张双曲线速度图。

验收口径：

- 动画中两棒始终体现为同向运动。
- 速度曲线在同一张图里逐渐靠拢并最终共速。

## 4.7 `EMI-022` 双棒 + 摩擦

本轮目标：

- 保留该模型作为双棒主展示项。
- 继续强调“先抑制相对运动，再比较摩擦终态”的课堂过程。

具体修改：

- 复用双棒基础的视觉修正：
  - 电流箭头贴棒
  - 速度/力箭头按大小变化
  - 双速度同图
- 结果区继续保留：
  - 先停棒
  - 是否共速
  - 最终是否全停

验收口径：

- 动画和结果区能对应出“先停 / 共速 / 再停”的阶段变化。
- 不需要额外展示双棒 + 电容。

## 4.8 双棒新增：一个棒受恒定外力

本轮目标：

- 新增双棒高频课堂模型。
- 先只做等距导轨，不做不等距导轨。

建议实现：

- 新增双棒变体，而不是硬塞进现有基础页说明里。
- 首页双棒家族改为：
  - 基础
  - 摩擦
  - 恒外力
- builder 也同步只开放这三支。

建议页面能力：

- 受恒外力的棒上明确画外力箭头。
- `v1-t / v2-t` 同图展示。
- `i-t` 单图展示。
- 结果区输出：
  - 当前速度关系
  - 是否趋于共速
  - 外力与安培力的阶段关系

验收口径：

- 一眼能分出哪根棒受外力。
- 外力、安培力、速度变化的因果顺序清楚。
- 首页和 builder 已能进入该模型。

## 4.9 `EMI-023` 双棒 + 电容

本轮处理策略：

- 不删代码。
- 不作为课堂主展示项。
- 从产品主入口、builder 默认模型和体验文案中撤下。

验收口径：

- 对外主线不再出现双棒 + 电容。
- 内部若仍保留页面，需明确是扩展模型，不是推荐模型。

## 4.10 `EMI-031` 竖直导轨单棒

本轮目标：

- 保留现有模型。
- 同步完成通性修正：
  - 电阻改成长方体
  - 电流箭头贴导体棒
  - 速度、安培力、重力箭头长度按量值变化

后续衔接：

- 单棒 + 电容的恒外力式若采用竖直舞台，需要尽量复用此页的竖直导轨舞台资产。

验收口径：

- 现有竖直导轨页和未来竖直电容页在视觉骨架上保持一致。

## 7. 风险与待确认项

- “单棒 + 电容 + 恒外力”是否严格按“匀加速”口径做，需要教研先定。
  - 如果坚持“严格匀加速”，必须在模型说明里明确采用教学简化。
  - 如果按完整耦合求解，就不能在页面文案里直接写成“匀加速”。
- 双棒恒外力的编号是否继续沿用 `EMI-02x`，可在真正接路由前再定。
- 双棒 + 电容本轮建议只做前台降级，不做物理删除，避免后续要恢复时重复开发。

## 8. 建议执行顺序

1. 先做通性视觉修正和图表能力升级。
