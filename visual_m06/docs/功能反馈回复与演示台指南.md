## 一、向量部分——可视化反馈.docx（9 项逐一回复）

### 1. 模长显示加约等于符号

**问题**：模长带小数时没有 ≈ 符号  
**实现方式**：将 ConceptLayer 和 CoordinateLayer 中的 `f(mag)` 替换为 `fmtApprox(mag)`。`fmtApprox` 函数判断数值是否为精确整数或简单分数，非精确时自动加 ≈ 前缀。  
**查看位置**：打开应用 → 选择"向量概念"或"坐标"运算 → 画布左上角 HUD 显示如 `|a| ≈ 4.472`

### 2. 相反向量拖动一侧另一侧不跟着变

**问题**：相反向量 a 和 -a 拖拽不联动  
**实现方式**：ParallelogramLayer 检测 `activePresetId === 'VEC-011-D'`（相反向量预设），拖拽 a 时自动 `setVecB([-v[0], -v[1]])`，拖拽 b 时反向设置 a。标签从 `b` 改为 `-a`。  
**查看位置**：选择"加法" → 右侧面板点击"相反向量"预设 → 拖拽任一端，另一端自动反向跟随

### 3. 同向/相反向量只能在预设方向拖动

**问题**：只能沿 x 轴方向拖，不能改变角度  
**实现方式**：同理检测 `activePresetId === 'VEC-011-E'`（同向向量预设），拖拽 a 时 `setVecB(v)` 保持同向。去掉了方向锁定逻辑，改为完全自由拖拽。  
**查看位置**：选择"加法" → 点击"同向向量"预设 → 可任意方向拖拽，两向量始终同向

### 4. 三角形法则向量 a、b 没有箭头

**问题**：首尾相接的向量没显示箭头  
**实现方式**：TriangleLayer 中为每段向量指定正确的 markerId：第一段 `arrow-a`、第二段 `arrow-b`、后续段 `arrow-chain-{i}`。ArrowDefs 中新增 `CHAIN_COLORS_DEFS` 定义 8 种链式箭头颜色的 marker。  
**查看位置**：选择"三角形法则" → 画布上每段向量（a、b 及链式向量）都有对应颜色的箭头

### 5. 减法可以展示 a+(-b) 对比

**问题**：只有 a-b 结果，看不到 a+(-b) 的过程  
**实现方式**：SubtractionLayer 新增计算 `aPlusNegB = add2D(vecA, negB)`，画布上增加三条虚线：① -b 从原点（灰色虚线）② -b 从 a 终点出发（首尾相接）③ a+(-b) 结果向量从原点（虚线），与 a-b 结果重合验证。  
**查看位置**：选择"减法" → 画布上同时显示 a-b（实线）和 a+(-b)（虚线），两者重合证明等价

### 6. 数乘根号不正常显示

**问题**：k=3√5 时显示为小数  
**实现方式**：ScalarLayer 标签从 `f(scalarK)` 改为 `fmtSmart(scalarK)`。`fmtSmart` 自动检测 `detectSurd` 是否匹配根号形式（支持 √2~√30），匹配则显示如 `3√5·a`。  
**查看位置**：选择"数乘" → 右侧面板 k 输入框中输入 `3*√(5)` → 画布标签显示 `3√5·a`

### 7. 点积自由调节夹角

**问题**：希望能自由拖拽调节两向量夹角  
**实现方式**：DotProductLayer 已有两个独立的 DragHandle 拖拽手柄，a 和 b 可以完全自由地向任意方向拖拽，夹角实时计算更新。  
**查看位置**：选择"a·b" → 拖拽 a 或 b 的端点到任意方向 → HUD 实时更新夹角和点积值

### 8. 3D 叉积轴不能随意拖动

**问题**：y 轴不能拖到朝右侧，坐标系固定  
**实现方式**：新建 `useRefFrameDrag` hook 实现 arcball 拖拽算法。右键按下记录起始球面点和当前四元数，移动时计算旋转四元数并更新 `sceneRotation`。Canvas3D 中用 `RotatableScene` 组件包裹所有 3D 内容，OrbitControls 释放右键。  
**查看位置**：切换到"叉积/空间向量/立体几何" → **右键拖拽**旋转整个坐标系（轴+向量+网格一起转）→ 左键仍为相机旋转 → 右侧面板"重置坐标系"按钮恢复默认

### 9. 演示台不能拖动整个向量

**问题**：创建向量后只能拖端点，不能拖整体平移  
**实现方式**：CanvasDemo 中创建向量后自动调用 `setTool('select')` 切换到选择模式。选择模式下点击向量中间部分可以拖拽整体平移（body drag），两个端点同步移动。  
**查看位置**：切换到"演示台" → 创建一个向量 → 直接点击向量箭杆中间拖拽即可整体移动

## 二、向量模块功能补充.docx（7 项逐一回复）

### 1. VEC-062 四个命名不清楚

**问题**：叉积的 4 个场景命名（i×j=k 等）不够直观  
**实现方式**：修改 `presets.ts` 中 VEC-062 的 name 字段：

| 预设 ID | 旧名称 | 新名称 |
|---------|--------|--------|
| VEC-062-A | i×j=k | 右手定则示例情形一 |
| VEC-062-B | j×k=i | 右手定则示例情形二 |
| VEC-062-C | \|3i×4j\|=12 | 面积计算 |
| VEC-062-D | 一般情形 | 一般的叉积运算 |

**查看位置**：切换到"叉积" → 右侧面板预设标签显示新名称

### 2. 首尾相接换名

**问题**：名称不够清楚  
**实现方式**：types.ts 中 OPERATION_META 已定义：parallelogram `label='平行四边形法则'` `shortLabel='加法'`，triangle `label='三角形法则'` `shortLabel='三角形法则'`。TopBar 显示 shortLabel。  
**查看位置**：顶部导航栏"基本运算"组中显示"加法"和"三角形法则"两个按钮

### 3. 增加投影向量功能

**问题**：缺少投影运算  
**实现方式**：新增 `projection` OperationType + `ProjectionLayer`（SVG 画布）+ `ProjectionParams`（参数面板）。画布显示：向量 a、向量 b（投影方向）、投影向量 proj（绿色粗线）、垂线（虚线）、直角标记。HUD 显示公式、投影长度、投影向量模长。  
**查看位置**：顶部导航栏"数量积"组 → 点击 **"投影"** → 拖拽 a/b 端点查看投影变化

### 4. 增加向量旋转功能

**问题**：缺少旋转运算  
**实现方式**：新增 `rotation` OperationType + `RotationLayer`（SVG 画布）+ `RotationParams`（参数面板，含角度滑块和精确输入）。画布显示：原始向量 a、旋转后向量 a'、旋转弧线、角度标注、虚线圆弧轨迹。  
**查看位置**：顶部导航栏"基本运算"组 → 点击 **"旋转"** → 用滑块或输入框调整角度 θ

### 5. 动态问题（起点终点都在动）

**实现方式**：演示台的向量支持 6 种约束模式（`constraint` 字段）：free / fixedStart / fixedEnd / lineStart / lineEnd / regionStart / regionEnd。配合动画系统，点可以设置圆形或直线运动路径，实现起点终点同时运动。  
**查看位置**：演示台 → 创建向量 → 选中向量 → 右侧面板设置约束类型 → 给端点配置运动路径 → 点播放

### 6. 终点在圆上运动

**实现方式**：向量的 `constraintLength` 属性定义圆半径，`fixedStart`/`fixedEnd` 约束类型将端点锁定在以另一端为圆心的圆上。拖拽时通过 `projectOntoConstraint()` 投影到圆弧。  
**查看位置**：演示台 → 创建向量 → 选中 → 右侧面板设置约束为"定长" → 拖拽终点只能在圆上滑动

### 7. 起点终点在直线/区域运动

**实现方式**：`lineStart/lineEnd` 约束将端点锁定在由 P1、P2 定义的无限直线上；`regionStart/regionEnd` 约束将端点锁定在矩形区域内。拖拽时自动投影到约束范围。  
**查看位置**：演示台 → 创建向量 → 选中 → 右侧面板设置直线/区域约束参数

### 5.4 向量运算（演示台内）

选中两个向量后，工具栏出现运算选项：

- **加法**：生成和向量
- **减法**：生成差向量
- **数乘**：输入标量 k，生成 k·v
- **点积**：显示标量结果

### 5.5 精确值与表达式系统

| 功能 | 说明 | 使用方式 |
|------|------|---------|
| √ 表达式输入 | 支持 √()、嵌套、四则混合 | 参数输入框中输入 `√(2)` 或 `1+√(3)` |
| √ 精确值显示 | 自动检测 a+b√c 形式（√2~√30） | 结果为根号时自动显示，如 `3√5` |
| π 表达式输入 | 支持 π、2π/3 等 | 输入框中输入 `π` 或 `2*π/3` |
| π 精确值显示 | 角度显示为 kπ/n | 特殊角自动识别，如 `π/4` |
| 分数显示 | 自动显示为 1/3 而非 0.33 | 结果为简单分数时自动生效 |
| LaTeX 渲染 | 文字标注支持 LaTeX | 创建文字 → 勾选"LaTeX" → 输入如 `\vec{a}` |
| CAS 符号计算 | 化简如 2√2+3√2=5√2 | 表达式输入时自动化简 |

### 5.6 动画与运动路径

#### 使用步骤

1. 在演示台创建一个 **标记点**
2. **选中该点**，右侧面板出现 **"运动路径"** 区域
3. 选择运动类型：
   - **圆形运动**：设置圆心 (cx, cy)、半径、速度、方向（顺/逆时针）
   - **直线运动**：设置起点 (x1, y1)、终点 (x2, y2)、速度、是否来回弹跳
4. 点击 **"保存运动路径"**
5. 画布底部出现 **播放控制栏**：▶ 播放 | ⏸ 暂停 | ⏹ 停止 | 0.5x / 1x / 2x / 4x 变速

#### 重要说明

- 运动路径只能给 **标记点** 设置，不能直接给向量设
- 如果需要向量端点运动：先创建标记点并设好运动路径，再用 **端点绑定** 把向量端点绑到该标记点上
- 播放控制栏 **只在有运动路径的点存在时才显示**

### 5.7 滑动条与变量绑定

#### 使用步骤

1. 在演示台创建一个 **滑动条**（设置名称如 `k`，范围如 -5 ~ 5）
2. 创建标记点，选中后在坐标输入框中输入 **表达式**，如 `x = k * √(2)`
3. 拖动滑动条，标记点位置跟随变化

#### 应用场景

- 参数化教学演示（如数乘系数 k 从 -2 到 2 连续变化）
- 动态轨迹探索（点的坐标由滑动条驱动）
- 向量运算中的标量 k 也支持表达式绑定

### 5.8 端点绑定

#### 使用场景

让两个不同实体的端点保持同步（如向量 a 的终点始终等于向量 b 的起点）。

#### 使用步骤

1. 创建两个需要绑定的实体（如两个向量）
2. 选中第一个向量的端点标记
3. 在右侧面板找到 **"绑定"** 区域
4. 选择要绑定的目标点
5. 绑定后移动任一点，绑定组内所有点同步跟随

#### 特性

- 支持 **传递绑定**：A 绑 B，B 绑 C → A/B/C 三点联动
- 解绑后各点恢复独立

### 5.9 约束系统

| 约束类型 | 效果 | 配置方式 |
|---------|------|---------|
| free | 无约束，自由拖拽 | 默认 |
| fixedStart / fixedEnd | 端点锁定在圆上（定长） | 设置 constraintLength |
| lineStart / lineEnd | 端点锁定在直线上 | 设置直线的两个端点坐标 |
| regionStart / regionEnd | 端点锁定在矩形区域内 | 设置区域的 min/max 坐标 |

画布上自动显示约束的可视化辅助：虚线圆弧、直线引导线、矩形区域边框。

### 5.10 交点吸附

拖拽或放置标记点时，自动吸附到：

- 已有标记点位置
- 线段-线段交点
- 线段-圆交点
- 圆-圆交点

吸附时光标附近显示提示标记。

### 5.11 场景导入/导出

右侧面板底部：

- **导出 JSON**：保存当前演示台所有实体、绑定关系为 JSON 文件
- **导入 JSON**：加载已保存的场景文件，支持 Undo 回退

### 5.12 自定义样式

- **9 色调色板**：灰 / 红 / 青 / 金 / 紫 / 蓝 / 橙 / 绿 / 蓝灰
- **线型**：实线 / 虚线
- **显示选项**：长度标注 / 斜率显示 / 坐标显示 / 面积显示 / 角度值显示

### 5.13 撤销/重做

所有操作均支持 **Ctrl+Z** 撤销 / **Ctrl+Shift+Z** 重做，历史栈最大 50 步。
