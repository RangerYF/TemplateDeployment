### 反馈⑨：约束轨迹功能（向量最值/范围题）

**用户原话**

**实现情况**
已实现。在演示台右侧面板底部新增"约束轨迹"区域，支持：

**约束表达式输入**
- LaTeX子集格式：`|\vec{a}|=1`、`\vec{a}\cdot\vec{b}=0`、`|\vec{a}-\vec{b}|=2`
- 支持 `\sqrt{}`、`\pi`、`\frac{}{}`
- 也兼容函数式写法：`mag(a)=1`、`dot(a,b)=0`
- 向量约束中的表达式用KaTeX渲染，显示为数学公式

**自动多向量轨迹**
- 约束中引用的每个向量都自动计算各自的可行轨迹
- 例如 `\vec{a}\cdot\vec{b}=0` 会同时显示向量a的可行区域和向量b的可行区域
- 拖动向量a → 向量b的轨迹实时更新（反之亦然）
- 无需手动选择"自由变量"

**输入验证**
- 引用不存在的向量时提示"请先创建向量 x"
- 点约束中引用的标记点也需预先创建

**目标函数**
- 可选输入目标表达式（如 `|\vec{b}|`），在轨迹上寻找并标注最小值/最大值点

**模板快速输入**
- 预置向量约束模板：向量模长、向量点积、向量差模、混合约束

**使用示例（题1：|a|=1，|a-b|+2√3·a·b=0，求|b|范围）**
1. 创建向量a（起点原点、终点(1,0)）和向量b
2. 添加约束：`|\vec{a}|=1`
3. 添加约束：`|\vec{a}-\vec{b}|+2\sqrt{3}\vec{a}\cdot\vec{b}=0`
4. 设置目标函数：`|\vec{b}|`
5. 拖动向量a沿单位圆转动 → 观察b的轨迹变化和目标函数极值

**当前限制与优化方向**
- 尚未实现约束投影（拖动向量时自动让其他向量跟随调整到满足约束的位置），目前仅显示可行轨迹
- 多约束交集的求解精度受 marching squares 分辨率限制（当前 0.05），细节可能丢失
- 对于3个及以上向量的复杂约束，计算量随向量数量线性增长，大量约束时可能出现延迟

  - 几何意义：叉积的模等于以 a、b 为邻边的平行四边形面积

  - 坐标公式：a×b = (a₂b₃−a₃b₂, a₃b₁−a₁b₃, a₁b₂−a₂b₁)

  - a×b 垂直于 a 和 b 构成的平面
  - 方向由右手定则确定
  - |a×b| = |a||b|sinθ = 平行四边形面积
  - a×b = 0 ⟺ a ∥ b

- **实时验证**：计算 (a×b)·a 和 (a×b)·b 验证垂直性
