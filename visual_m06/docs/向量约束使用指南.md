# 向量约束轨迹使用指南

## 1. 约束语法说明

### 1.1 两类约束

| 类型 | 适用场景 | 输入格式 |
|------|----------|----------|
| **点约束** | 未知点 P 满足与已知点的几何关系 | `dist(P,A)=3`、`mag(P)=4` |
| **向量约束** | 向量间满足模长/点积/混合条件 | `|\vec{a}|=1`、`\vec{a}\cdot\vec{b}=0` |

### 1.2 向量约束语法（LaTeX 子集）

**基础标记：**
- `\vec{a}` — 引用画布上名为 a 的向量
- `\cdot` — 在两个 `\vec{}` 之间为点积，其他位置为乘法
- `|\vec{a}|` — 向量 a 的模长

**运算支持：**
| 写法 | 含义 |
|------|------|
| `\|\vec{a}\|` | 向量模长 |
| `\vec{a}\cdot\vec{b}` | 向量点积 |
| `\|\vec{a}-\vec{b}\|` | 差向量的模长 |
| `\|\vec{a}+\vec{b}\|` | 和向量的模长 |
| `2\vec{a}` | 数乘向量 |
| `\sqrt{3}` | 根号 3 |
| `\pi` | π |
| `\frac{a}{b}` | 分数 a/b |

**等式格式：** 左边 = 右边，如 `|\vec{a}|=1` 或 `|\vec{a}-\vec{b}|+2\sqrt{3}\vec{a}\cdot\vec{b}=0`

**兼容函数式写法（可选）：** `mag(a-b)`、`dot(a,b)`，方便程序化生成。

### 1.3 点约束语法（已有功能）

| 函数 | 含义 | 示例 |
|------|------|------|
| `dist(P,A)` | P 到 A 的距离 | `dist(P,A)=3` |
| `mag(P)` | P 到原点的距离 | `mag(P)=4` |
| `dot(P,A)` | OP·OA 点积 | `dot(P,A)=0` |
| `angle(A,P,B)` | ∠APB 的角度 | `angle(A,P,B)=90` |
| `distLine(P,A,B)` | P 到直线 AB 的距离 | `distLine(P,A,B)=2` |

### 1.4 自由变量

向量约束需要指定一个**自由变量**（自由向量），其终点坐标作为 (x,y) 变量在坐标平面上扫描。其他向量保持固定。

在"约束轨迹"面板中，通过"自由变量"下拉框选择。

---

## 2. 操作步骤

### 通用流程

1. 在画布上创建所需向量（确保每个向量有唯一名称）
2. 展开右侧面板底部的"约束轨迹"区域
3. 在"自由变量"下拉框中选择要求解的向量
4. 输入约束表达式（可从模板选择或手动输入）
5. 点击 + 或回车添加约束
6. 画布上自动显示满足约束的轨迹曲线
7. （可选）在"目标函数"输入框中输入目标表达式，查看极值

## 3. 高考题示例

### 题目 1：已知 |⃗a|=1，|⃗a−⃗b|+2√3·⃗a·⃗b=0，求 |⃗b| 的范围

**设置步骤：**

1. **创建向量 a：** 在画布空白处拖拽创建，命名为 `a`
2. **创建向量 b：** 再创建一个向量，命名为 `b`
3. **固定向量 a 的模长：** 调整 a 的终点使其长度约为 1（或使用坐标精确设置起点(0,0)终点(1,0)）
4. **选择自由变量：** 下拉框选择 `b`
5. **添加约束 1：** `|\vec{a}|=1`
6. **添加约束 2：** `|\vec{a}-\vec{b}|+2\sqrt{3}\vec{a}\cdot\vec{b}=0`
7. **设置目标函数：** 输入 `|\vec{b}|`（或函数写法 `mag(b)`）
8. **观察结果：**
   - 画布上显示满足两个约束交集的轨迹
   - 目标函数显示 |⃗b| 的最小值和最大值

**拓展演示：** 拖拽向量 a 旋转方向，观察轨迹实时变化，验证结论不依赖 a 的方向。

---

### 题目 2：已知 |⃗a|=2，|⃗b|=1，⃗a·⃗b=1，求 |⃗a+t⃗b| 的最小值

**设置步骤：**

1. **创建向量 a：** 起点(0,0)终点(2,0)，命名为 `a`，|a|=2
2. **创建向量 b：** 命名为 `b`，这里 b 是自由变量
3. **选择自由变量：** `b`
4. **添加约束 1：** `|\vec{a}|=2`
5. **添加约束 2：** `|\vec{b}|=1`
6. **添加约束 3：** `\vec{a}\cdot\vec{b}=1`
7. **观察轨迹：** 三条约束交集决定 b 的可行终点位置

**分析：** 这道题中 t 为参数，|⃗a+t⃗b| 的最小值等于 a 到 b 方向的垂直距离。约束交集确定 b 的方向，从而确定最小值为 √3。

---

### 题目 3：|⃗a|=1，|⃗b|=√3，|⃗a−⃗b|=1，求 |2⃗a+⃗b| 的值

**设置步骤：**

1. **创建向量 a：** 起点(0,0)终点(1,0)，命名为 `a`
2. **创建向量 b：** 命名为 `b`
3. **选择自由变量：** `b`
4. **添加约束 1：** `|\vec{a}|=1`
5. **添加约束 2：** `|\vec{b}|=\sqrt{3}`
6. **添加约束 3：** `|\vec{a}-\vec{b}|=1`
7. **设置目标函数：** `|2\vec{a}+\vec{b}|`（或 `mag(2*a+b)`）
8. **观察结果：**
   - 三条约束的交集是有限个点（或弧段）
   - 目标函数给出最小/最大值
   - 本题 |2⃗a+⃗b| = √7

**可视化验证：** 轨迹显示 b 的终点在约束限定的位置，目标函数值稳定在 √7 ≈ 2.646。

## 4. 参数化演示方法

### 4.1 滑块绑定向量端点

可以将向量端点坐标绑定到滑块表达式，实现参数化控制：
1. 创建滑块（如 `t`，范围 0~2π）
2. 选中向量端点，在坐标的表达式栏输入 `cos(t)` 和 `sin(t)`
3. 拖动滑块 → 向量方向连续变化 → 约束轨迹实时更新

### 4.2 实时观察目标函数

设置目标函数后，拖拽固定向量或调整滑块，面板中的最小值/最大值实时更新，可动态验证"在什么条件下取极值"。

---

## 5. 注意事项

- **命名唯一性：** 向量、标记点、滑块不能同名。重名时输入框会显示红色提示。
- **自由变量必选：** 使用向量约束时必须选择自由变量，否则不会显示轨迹。
- **表达式验证：** 引用不存在的向量会提示"请先创建向量 x"。
- **混用约束：** 点约束和向量约束可以同时使用，各自独立求解。
- **轨迹颜色：** 点击约束条目左侧的彩色圆点可切换颜色；点击表达式文字可显示/隐藏该约束轨迹。
