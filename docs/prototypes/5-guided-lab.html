步骤 2 / 5分析受力

观察物体在斜面上受到的三个力：

• 重力 mg — 竖直向下，大小为 mg = 2.0 × 9.8 = 19.6 N

• 支持力 N — 垂直斜面向上，大小为 N = mg cos30° = 17.0 N

• 摩擦力 f — 沿斜面向上（阻碍下滑），大小为 f = μN = 0.3 × 17.0 = 5.1 N

地球绕太阳做近似圆周运动。万有引力提供圆周运动所需的向心力。

公式：F = GMm/r² = mv²/r

步骤 1 / 4认识电路

这是一个串联电路：电源（12V）连接两个电阻 R₁=4Ω 和 R₂=8Ω。

串联特点：电流处处相等，总电压 = 各分压之和。
