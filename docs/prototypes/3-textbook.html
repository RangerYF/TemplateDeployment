教学要点

▾
•沿斜面方向和垂直斜面方向建立坐标系，分解重力
•沿斜面分力 mg sinθ 是驱动物体下滑的力
•垂直斜面方向平衡：N = mg cosθ
•摩擦力 f = μN，方向沿斜面向上阻碍下滑
•当 tanθ > μ 时物体加速下滑
•万有引力 F = GMm/r² 提供向心力
•开普勒第二定律：等时间扫过面积相等
•轨道速度 v = √(GM/r)，半径越大速度越小
•周期公式 T² = 4π²r³/(GM)
•串联电路中电流处处相等 I = U/(R₁+R₂)
•各电阻分压与阻值成正比 U₁/U₂ = R₁/R₂
•总电压等于各分压之和 U = U₁ + U₂
•功率 P = UI = I²R = U²/R
