# 方案A：物理模板前端优化细化方案

> 版本：V1.0 | 日期：2026-06-03 | 智教联思产品技术团队

## 1. 方案定位与目标

### 1.1 定位

方案A是对现有5个物理模板仓库的**前端优化**，在不改变代码仓库结构和物理引擎的前提下，通过减少不必要的信息展示和交互按钮、统一前端布局、提升视觉品质来改善教师使用体验。

方案A与方案B（全新场景化模板体系，独立仓库 `D:\repo\Scenario-based-Template`）并行推进，互不依赖。

### 1.2 目标

- 教师操作步骤从7步降低至4步以内
- 可见参数从10-20个精简至3-5个核心参数（其余折叠或删除）
- 5个物理模板的前端布局、控件风格、交互模式达到一致
- 各模板视觉品质按自身特点做到最优
- 支持桌面投屏和移动端基础浏览

## 2. 改造分类策略

现有物理模板按交互形态分为两类，采用不同的优化策略：

### 2.1 调参型模板 — 统一布局架构

适用模板：
- **电磁场可视化**（phys_template_p01 P-08）
- **电磁感应**（phys_template_p01 P-13）
- **光学实验台**（phys_template_p03 全部5个模块）
- **热学模拟器**（physics07 全部5个场景）
- **天体运动与引力**（visual_p9）

共同特征：用户操作流程为「选预设/场景 → 调参数 → 观察画布变化 → 读取数据」，不涉及自由搭建。

优化策略：**统一布局架构 + 参数精简 + 视觉升级**

### 2.2 搭建型模板 — 减法 + 美化

适用模板：
- **力学沙盒**（phys_template_mechanics 全部6个子模块）
- **电路搭建**（phys_template_p01 P-04）
- **物理沙盒**（phys_template_p01 Sandbox）

共同特征：用户需要从元件库/对象库中拖拽物体到画布自由组装，再运行观察。

优化策略：**保留编辑器核心能力，精简工具模式和参数，统一视觉风格**（不改变布局结构）

## 3. 调参型模板：统一布局架构设计

### 3.1 页面骨架

```
桌面端 (≥1024px)：
┌────────────────────────────────────────────────────────────┐
│  TopBar                                                     │
│  [模板标题]  [预设选择▾]        [状态] [▶ ⏸ ↺ 速度▾] [?]  │
├──────────────────────────────────────────┬──────────────────┤
│                                          │                  │
│                                          │  参数区           │
│                                          │  ┌──────────┐   │
│            主画布                         │  │ 核心参数   │   │
│            (Canvas 2D / Three.js)        │  │ 3-5个     │   │
│                                          │  ├──────────┤   │
│                                          │  │▸ 高级设置  │   │
│                                          │  ├──────────┤   │
│                                          │  │ 读数区     │   │
│                                          │  │ 实时数据   │   │
│                                          │  └──────────┘   │
└──────────────────────────────────────────┴──────────────────┘
```

### 3.2 TopBar 设计（高度 44-48px）

包含元素：
- **模板标题**：当前模板/模块名称（如"光的折射与全反射"）
- **预设选择器**：下拉选择预设场景配置（如有多个预设时显示）
- **运行状态标识**：已就绪 / 运行中 / 已暂停（badge样式）
- **播放控制组**：运行(▶) / 暂停(⏸) / 重置(↺) 按钮
- **速度调节**：1x / 0.5x / 0.25x / 2x 下拉选择
- **教学要点按钮**（?或📖图标）：点击弹出浮窗，展示本模板的教学要点和关键公式

移除元素（调参型模板）：
- 模块切换Tab（不需要，各子模块已通过URL独立入口区分）
- 工具模式切换（选择/平移/力/关节等 — 调参型不需要）
- 撤销/重做（调参操作是实时的，不需要撤销）
- 截图/导出（低频功能，如保留可收进右上角「更多」菜单）

### 3.3 主画布区域

- 占据除TopBar和右侧面板之外的全部空间
- 画布技术按模板选用：Canvas 2D（力学/电路/波动/热学）或 Three.js（天体/电磁场3D/光学）
- 画布背景按主题适配：亮色模式下为浅灰底+柔和网格，暗色模式下为深色底+暗色网格
- 画布内标注（力矢量标签、数值、角度等）使用半透明背景pill确保可读性
- 支持鼠标/触摸的画布交互（拖拽视角、缩放、点击选择物体查看信息）

### 3.4 右侧参数面板

宽度：300-340px（桌面端固定展示）

内部分区（从上到下）：

**区域1：核心参数（默认展示）**
- 3-5个直接影响核心物理现象的参数
- 每个参数包含：标签 + 当前值（带单位） + 滑块
- 重要参数可同时提供滑块和数值输入框
- 开关型参数使用Toggle组件（如"显示分力"）

**区域2：高级设置（折叠区，默认收起）**
- 点击"▸ 高级设置"展开
- 影响细节但不影响核心理解的参数（弹性系数、重力加速度、空气阻力等）
- 与核心参数使用相同的控件样式

**区域3：实时读数**
- 当前仿真状态的关键物理量
- 每行：颜色标识圆点 + 物理量名称 + 数值 + 单位
- 颜色标识与画布中对应的力/矢量颜色一致

### 3.5 教学要点浮窗

- 通过TopBar右侧的教学要点按钮触发
- 浮窗形式：模态对话框或右侧滑出面板
- 内容包含：
  - 本模板的教学目标（1-2句话）
  - 关键物理知识点（3-5个要点）
  - 核心公式（带变量说明）
- 内容按模板预配置，不动态生成
- 浮窗关闭后不影响画布和参数操作

### 3.6 响应式布局

| 断点 | 屏幕宽度 | 画布 | 参数面板 | TopBar |
|------|----------|------|----------|--------|
| 桌面 | ≥1024px | 左侧，与面板并列 | 右侧常驻展示 300-340px | 完整展示所有元素 |
| 平板 | 768-1024px | 全宽 | 收起为右侧抽屉，点击按钮滑出 | 精简，部分文字改为图标 |
| 手机 | <768px | 全宽 | 底部半屏抽屉，上滑展开 | 仅保留标题+播放按钮 |

所有断点下的核心原则：
- 画布优先，永远保持可见且不变形
- 参数面板是"让路"的一方
- 不出现横向滚动条
- 不出现白屏或布局崩溃

## 4. 搭建型模板：减法 + 美化方案

### 4.1 保留的核心能力

- 左侧对象库/元件库面板
- 画布自由拖拽放置
- 物体间连接/关节
- 撤销/重做
- 编辑模式 ↔ 运行模式切换

### 4.2 精简内容

工具模式精简：
- **保留**：选择工具、平移工具
- **评估保留**：力工具（力学模板需要）、连线工具（电路模板需要）
- **去掉或合并**：关节工具（可合并到选择工具的右键菜单）

对象库精简：
- 按模板实际教学需求审查，去掉低频使用的物体类型
- 力学：保留方块、球体、斜面、地面；评估凹槽、半球、传送带的使用频率
- 电路：保留核心元件（电源、电阻、开关、导线、电表），去掉极低频元件

属性面板精简：
- 与调参型相同的分层策略：核心参数默认展示，高级参数折叠，无关参数删除

### 4.3 视觉对齐

- TopBar样式与调参型模板一致（高度、配色、控件样式）
- 按钮/滑块/开关等控件使用相同的组件样式
- 对象库面板的卡片样式统一
- 画布背景风格统一
- 支持与调参型相同的亮色/暗色主题切换

## 5. 视觉主题系统

### 5.1 双主题设计

- **默认亮色主题**：适合课堂投屏、日常使用
- **暗色主题**：可切换，适合暗室演示、视觉效果更突出

主题切换入口：TopBar右侧图标按钮（太阳/月亮图标）

### 5.2 亮色主题色板

```

面板/卡片背景：#ffffff
面板边框：#e2e8f0
文字主色：#0f172a
文字辅色：#64748b
主强调色（物理）：#2563eb（蓝）
成功/运行：#16a34a
警告：#d97706
危险/重力：#dc2626
摩擦力：#16a34a
支持力/电场：#2563eb
控件高度：36px

```

### 5.3 暗色主题色板

```
背景色：#0a0e1a
面板/卡片背景：#111827
面板边框：rgba(255,255,255,0.08)

文字辅色：#64748b
主强调色：#3b82f6（蓝，比亮色稍亮）
其余语义色相同但亮度调高以保证对比度
```

### 5.4 控件样式统一清单

以下控件在所有模板中使用统一样式：

| 控件 | 规格 |
|------|------|
| 按钮 | 高度36px，圆角8px，主操作实底、次操作描边、工具栏图标按钮 |
| 滑块 | 轨道高度4-6px，滑块圆形直径16-18px，带标签+当前值+单位 |
| 开关 | 宽40px 高22px，开启态强调色，关闭态灰色 |
| 下拉选择 | 高度36px，圆角8px，右侧箭头图标 |
| 数值输入 | 高度36px，带单位后缀，支持上下调节 |
| 状态Badge | 圆角10px，小字号，语义色背景 |
| 读数行 | 左侧颜色圆点+名称，右侧加粗数值+单位 |

## 6. 各模板视觉升级方案

按每个模板的特点和当前品质做针对性升级，不设统一上限。

### 6.1 力学模板（phys_template_mechanics）

当前品质：4.0/10（线稿风格，无光影）

升级方向：
- 物体渲染：添加径向渐变填充 + 阴影（drop-shadow）+ 圆角
- 力矢量：加粗 + 发光效果（shadowBlur）+ 半透明背景标签pill
- 斜面/地面：渐变填充 + 标准教科书式斜线阴影标记
- 运动轨迹：半透明渐变拖尾
- 参考线/网格：柔和细线，不喧宾夺主

技术：Canvas 2D增强（不引入Three.js）

### 6.2 统一模拟器-电路（phys_template_p01 P-04）

当前品质：5.0/10（功能性渲染）

升级方向：
- 导线：圆滑连接 + 微妙阴影
- 电流可视化：沿导线移动的发光粒子动画
- 元件：更精致的符号渲染（渐变填充、圆角）
- 电表读数：仪表盘风格的指针动画

技术：Canvas 2D + SVG元件叠加

### 6.3 统一模拟器-电磁场（phys_template_p01 P-08/P-13）

当前品质：5.0/10

升级方向：
- 场线：颜色映射场强 + 粗细变化表示强度
- 粒子运动：发光轨迹 + 速度相关的拖尾长度
- 电荷/磁体：径向渐变 + 光晕效果

技术：Canvas 2D增强，评估部分场景引入Three.js做3D场线

### 6.4 光学模板（phys_template_p03）

当前品质：6.5/10（已有SVG多层光晕和Three.js折射3D）

升级方向：
- 统一所有光学模块的渲染风格（当前折射3D用Three.js，其他用SVG，风格不一致）
- 光线效果增强：更真实的色散彩虹、更柔和的光晕
- 透镜/棱镜：玻璃质感材质（Three.js PBR或Canvas渐变模拟）
- 干涉/衍射图样：更细腻的条纹渲染

技术：评估将更多模块迁移到Three.js统一渲染

### 6.5 热学模板（physics07）

当前品质：7.5/10（最高，已有3D质感+bloom）

升级方向：
- 粒子系统优化：更流畅的分子运动动画
- 温度色彩映射：容器颜色随温度变化（蓝→红渐变）
- 活塞/容器：增强3D质感的金属/玻璃材质
- 保持现有渲染品质标杆地位

技术：保持Canvas 2D，评估粒子量大的场景使用OffscreenCanvas

### 6.6 天体模板（visual_p9）

当前品质：7.0/10（径向渐变+光晕效果不错）

升级方向：
- **用Three.js重构画布**：3D行星球体 + 纹理贴图（地球/木星等真实纹理）
- 星空背景：Three.js粒子系统，带微弱闪烁动画
- 太阳：体积光效果 + 日冕粒子
- 轨道：3D椭圆轨道 + 轨迹拖尾
- 引力场可视化：空间扭曲网格效果（可选）

技术：Three.js全面重构

## 7. 参数精简指引

### 7.1 精简原则

每个模板按以下规则审查所有参数：

| 层级 | 标准 | 处理方式 |
|------|------|----------|
| 核心参数 | 直接影响核心物理现象，教师几乎每次都调 | 默认展示，≤5个 |
| 高级参数 | 影响细节但不影响核心理解，偶尔调整 | 折叠到"高级设置"区 |
| 删除参数 | 纯技术/调试用，与教学无关 | 直接移除，不暴露给用户 |

### 7.2 各模板参数审查参考

#### 力学模板（以斜面场景为例）

| 参数 | 当前 | 建议层级 |
|------|------|----------|
| 质量 | 暴露 | **核心** |
| 斜面角度 | 暴露 | **核心** |
| 摩擦系数 | 暴露 | **核心** |
| 初速度 | 暴露 | **核心** |
| 显示分力 | 暴露 | **核心** |
| 弹性系数 | 暴露 | 高级 |
| 重力加速度 | 暴露 | 高级 |
| 物体宽度 | 暴露 | **删除** |
| 物体高度 | 暴露 | **删除** |
| 速度y分量 | 暴露 | **删除** |
| 精确位置x | 暴露 | **删除** |
| 精确位置y | 暴露 | **删除** |
| 锁定旋转 | 暴露 | **删除** |

## 8. 实施策略

### 8.1 执行顺序

1. **先统一控件和主题系统**：提取/对齐所有模板的Button/Slider/Switch/Toggle/Badge等控件样式和亮色/暗色主题变量
2. **再统一调参型布局**：TopBar + 画布 + 右侧面板骨架，逐模板适配
3. **同步做参数精简**：在适配布局时同步做参数审查和分层
4. **最后做视觉升级**：各模板按6.1-6.6的方案做Canvas/Three.js渲染升级
5. **搭建型模板收尾**：对齐视觉风格 + 精简工具/参数

### 8.2 注意事项

- 不改变物理引擎和计算逻辑
- 不改变snapshot/bridge协议
- 不改变已有的URL路由和部署结构
- 不新增功能（教学要点浮窗除外），只做减法和品质提升
- 所有改动需确保现有功能不受影响

## 9. 验收标准

方案A改造完成后，各模板应满足：

- [ ] 调参型模板布局结构一致（TopBar+画布+右侧面板）
- [ ] 所有模板控件样式统一（按钮/滑块/开关/输入框/Badge）
- [ ] 核心参数 ≤5个默认展示，其余折叠或删除
- [ ] TopBar仅包含规定元素，无冗余按钮
- [ ] 亮色/暗色主题可切换，两套主题下均无视觉异常
- [ ] 桌面端（≥1024px）布局正确
- [ ] 平板端（768-1024px）参数面板可抽屉展开
- [ ] 手机端（<768px）不白屏不崩溃，画布可见
- [ ] 各模板视觉品质较改造前有明显提升
- [ ] 教学要点浮窗功能可用
- [ ] 原有功能无回归（物理仿真、参数调节、播放控制均正常）
- [ ] bridge/snapshot协议不受影响
